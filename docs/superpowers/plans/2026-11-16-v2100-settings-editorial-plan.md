# 2.10.0 · 设置页编辑部化 + 空态拖环提示（2026-11-16 立项）

> 状态：代码侧完成，待使用者确认视觉方向与真机走查；版本号未提升、未出 Release 包。
> 范围：设置页呈现层 + 首页空态手势提示；业务写入、持久化键、导航、权限、主题素材全部不动。
> 触发：使用者「UI 和展示以及用户交互还有很大空间」+ 项目停滞一段时间后的恢复迭代。
> 本轮先做两件低风险、可回退的事：设置页去卡片统一到编辑部语言；空态环心给一次「可拖动」轻提示。

## 1. 诊断

- 统计页自 1.5.0 去卡片化后，以「分节微标签 + 右延发丝线 + 内容浮在纸面」为版面骨架；
  设置页仍是 `PaperPanel` 四连卡：圆角大底、卡内再套 chips/group 小底，背景花纹从卡片边缘透出。
- 1.3.1 真机否决「盒子套盒子、边框过多、面板遮挡主图」；2.0.0 首页也已改编辑部构图。
  设置页因此是全 app 唯一还停留在旧卡片语言的页面，视觉断裂最明显。
- 本次不新增控件、不改变任何设置项的位置语义，只改变它们被承载的方式。

## 2. 设计决定

1. **无页面级卡片**：移除设置页的 `PaperPanel`；四个分区改为
   `EditorialSectionLabel`（微字距标签 + 发丝线）+ 直接落在纸面的内容。
2. **共享分节件**：统计页的私有 `StatsSectionLabel` 提升为
   `core:designsystem` 的 `EditorialSectionLabel`（rules §二.2 第二次使用即下沉）。
   统计页改用共享件，像素逐位不变。
3. **行级分隔**：分区内用 1dp、`laceColor` 22% 的发丝线分隔行，代替卡片内边距；
   交互控件（开关、chips、主题入口、步进器）保留自身的小面积底色/描边，作为「可操作」的提示。
4. **提醒状态行去盒**：状态点 + 文案 + 「测试提醒」直接成行，不再是一条浅色圆角底。
5. **提醒稳定性入口去卡**：整行可点 + 按压缩放 + 右侧箭头，归入「提醒稳定性」分节。
6. **文案库**：分区标题改用共享 `EditorialSectionLabel`；说明与「恢复默认」放在标题下一行，
   折叠分组保留既有浅色容器（它们是行级交互容器，不是页面卡片）。
7. **节奏**：分区间距 20dp、分区内行距 12dp；页底 32dp 呼吸。大字体允许自然滚动，不截断。

## 3. 非目标

- 不改任何设置项的业务行为、持久化键、默认值、校验、通知调度。
- 不改主题色、背景素材、花边、粒子、猫咪、首页、统计页内容。
- 不新增设置项，不引入新的设置页导航层级。
- 不把提醒状态行做成新的「状态卡」；不新增图标素材。

## 4. 实施步骤

1. 新增 `EditorialSectionLabel`（支持可选 trailing 动作）；统计页切换，删除私有实现。
2. 设置页移除 `SettingsCard`/`PaperPanel`，改为 `SettingsSection` + 发丝线；
   重排饮水目标、喝水提醒、外观与声音、提醒稳定性四个分区。
3. 文案库分区头改用共享标签；保留触控下限与既有对话框。
4. 新增 `SettingsEditorialLayoutTest`：四分区可达、两个行级动作触控高度 ≥ 48dp。
5. 以 `AWAKE_VISUAL_BASELINE=update` 重拍设置页 12 张基线；逐主题目检；
   统计页基线应零漂移（共享件逐位等价）。

## 6. 风险与回退

- **风险**：去卡后内容直接落在花纹背景上，局部对比度可能下降。
  - 缓解：`ReadingField` 保持；文字继续走 `greetingColor`/`greetingSubColor`；
    控件保留小面积底色；基线逐主题目检。
- **风险**：页面变长。
  - 缓解：分区间距 20dp、行距 12dp；设置页本就允许滚动，不追求一屏。
- **回退**：纯呈现层改动，回退本版提交即可恢复卡片布局；不涉及数据迁移。

## 7. 增补：空态拖环提示（2026-11-16）

### 诊断

- 「环即把手」自 2.2.0 起是招牌交互，但可发现性为零：使用者只看到猫的「点击我试试~」，
  不知道环本身可以沿切向拖动；`松手记录`只在拖动中才出现。
- 外部参考：NN/g 指出拖拽控件需要**可见手柄 + 抓取态 + 即时反馈**，不要靠隐藏手势；
  WCAG 2.2 SC 2.5.7 要求拖动功能必须有**单指替代路径**（本项目已有点按环记一杯 + 快捷量）；
  NN/g 的 onboarding 研究建议用**一次性的上下文提示**而不是前置教学弹窗。
  来源：NN/g《Drag-and-Drop: A Blessing and a Curse》https://www.nngroup.com/articles/drag-drop/ ；
  WCAG 2.2 SC 2.5.7 https://www.w3.org/WAI/WCAG22/Understanding/dragging-movements.html ；
  NN/g《Onboarding Tutorials》https://www.nngroup.com/articles/onboarding-tutorials/ 。
- 约束：AGENTS.md 禁止借视觉优化新增持久化键；因此不做「已看过」标记，改用空态驱动。

### 设计决定

1. **只在空态出现**：`totalMl == 0` 且无环心文案/拖环预览/达标庆祝时，环心默认小字从
   「今日进度」换成「可拖动记录」；第一次记录后立即收回，不循环、不弹窗。
2. **一次轻演示**：空态出现后静置 600ms，沿环端画一段 26° 的虚线弧 + 一枚珠点前移再回位
   （1100ms，正弦包络）；只进 draw 相，不改变真实进度、不逐帧重组。
3. **减少动态**：不播放珠点移动，只保留静态「可拖动记录」文案（WCAG/系统设置口径）。
4. **不新增持久化键**：`rememberSaveable` 只管本次进程/旋转；冷启动空态会再出现一次，
   有记录时永不出现。提示是 affordance，不是 onboarding 状态机。
5. **不改变点按语义**：环区点按仍立即记一杯（§19 无障碍等价路径），只多一层视觉教学。
