# alpha11 · 蓝瓷主题、圣职可见度与次级页面重设计

## 产品边界
仍只记录和提醒喝水。猫咪提示、主题和装饰不承载收藏、养成或奖励。

## 本轮设计与实现
1. 清晨薄荷更名为「晨雾蓝瓷」，瓷白/雾蓝/深蓝灰替代绿色。保留 EMERALD、FIXED_EMERALD 持久化键与四时段映射，避免设置迁移；沿用已有蓝色氛围素材，不需补图。
2. 圣职背景保留原图透明度，将饰物轮廓转为更清楚的冷银灰，再合成瓷白纸面；独立控制背景、中央遮罩与混合方式，禁止把白主题做成灰黑主题。没有要求用户新素材。
3. 猫右上方提示「点击我试试~」；占用猫自身区域而非叠盖统计/按钮。提示可点，触发同一个摸猫操作。一次提示在当前页面会话内消失，回应出现时让位；不闪烁、不反复催促。
4. 回应文字左对齐，保留自然换行与自适应高度；长文本不截断、单字尾行不居中。
5. 统计页采用统一页头、今日总量与细进度条、事实摘要、七日图表、记录列表。图表可选择查看某日值，提供无障碍选择路径；零记录简洁展示。
6. 修复柱图错峰动画终态比例：每列在总动画完成时都必须到达 100%，而非后列剩余 64%。新增纯数学回归。
7. 我的页采用清晰分组、48dp 步进器和均匀间距；主题改为当前主题预览入口＋可滚动选择面板，减少主页面长度，选中立即生效、可返回；声音与外观合并。不改变设置持久化/通知权限逻辑。
8. 统计和设置共用页头/纸面语言，统计使用安静粒子，数据和按钮为主，边缘素材为辅。
