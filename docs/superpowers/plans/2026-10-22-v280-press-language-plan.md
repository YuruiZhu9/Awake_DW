# v2.8.0 · 按压语言统一 + 状态过渡补齐（2026-10-22 立项）

## 背景与触发

2.6.0 完成动效二阶（数字滚动、三通道同拍）、2.7.0 完成视觉回归基线后，P0/P1 工程欠账已清。本版沿「无需新方向决策」的路线，以 Emil Kowalski 设计工程标尺对**交互响应细节**做一轮收尾审计，发现两类既定手感语言未铺满：

1. **按压缩放重复三处**：`LogButton`（首页主按钮）、`ProgressRing`（环即把手）、引导页 `PrimaryButton` 各自持有一份完全相同的实现（0.97f / spring damping 0.5 / StiffnessMedium / 减少动态直显）——正是 rules §二.2「同一逻辑重复到第三处，当场收敛」的触发点。
2. **次级触点只有库存 ripple**：快捷量胶囊、间隔档 chips、主题色卡（设置页 + 引导页）、主题入口、步进按钮仍走 M3 默认水波纹；与本 app 自 2.2.0「环即把手」起确立的安静按压语言（缩放、无水波纹）不一致。
3. **时间线状态变化零过渡**：今日时间线删除一条、展开/收起「显示更多」时行直接跳变——「元素无过渡地出现或消失，观感是坏掉了」。

## 设计决策（Emil 标尺逐条）

| 现状（Before） | 本版（After） | 为什么 |
| --- | --- | --- |
| 按压缩放逻辑在 3 个文件各写一份 | `core:designsystem` 共享 `Modifier.pressScale(interactionSource)` + `MotionTokens.PRESS_SCALE = 0.97f`，三处改引用（行为逐位不变） | 同一逻辑第三处重复必须收敛（rules §二.2）；共享后未来触点一键继承 |
| 快捷量/间隔/主题卡/入口/步进 = M3 默认水波纹 | 统一为共享按压缩放（0.97，spring 回弹），indication 置空 | 水波纹是库存语言；主按钮/环/时间线早已无纹缩放。全 app 一种按压回答，安静且一致 |
| 时间线删除 / 展开 / 收起行直接跳变 | 时间线容器 `animateContentSize`（反馈拍 240ms + EasingStandard；减少动态 snap 直变） | 尺寸过渡可中断、确定性强；与三通道同拍（§12.2）共用 240ms |
| （保持）主按钮/环/引导主按钮手感 | 不动：0.97 / spring 0.5 / StiffnessMedium 由 2.2.0 真机确认过的手感原样收敛 | 已验证的手感不借重构改参数 |

**不动画的（Emil 频率标尺）**：主题卡选中态的边框/底色切换保持瞬时（低频操作，状态要「立刻看清」）；底栏选中 spring（1.9.0）、三通道 240ms（2.6.0）、数字滚动 500ms（2.6.0）、时间线逐条 40ms 错峰（既有）全部原样。

**假设显式标注（rules §七.3）**：把次级触点的库存水波纹替换为本 app 既有缩放语言，属于交互反馈呈现层统一（基线 §3 允许），不改变任何操作语义、触控目标与无障碍路径；已按 2.2.0「环即把手」的先例办理，真机走查时一并确认。

## 范围

- `core:designsystem`：新增 `animation/PressScale.kt`；`MotionTokens` 收录 `PRESS_SCALE`；`LogButton` / `ProgressRing` 改引用。
- `feature/home`：`QuickSipChip` 接入按压缩放（触感保留）。
- `feature/settings`：`SelectableChip` / `ThemeChoiceCard` / `ThemePickerEntry` / `StepButton` 接入。
- `feature/onboarding`：`PrimaryButton` 改引用；主题色卡接入。
- `feature/stats`：`TodayTimeline` 容器尺寸过渡。
- 测试：`PressScaleTest`（按压收敛 0.97、释放回 1、减少动态恒 1）；时间线删除/展开过渡测试；既有套件全绿。

## 非目标

- 不动业务、持久化键、导航、权限、三通道分工、素材与主题色板。
- 不做主题卡选中态的补间动画（低频动作保持瞬时）；不动底栏、开屏与页面转场。
- 不给静态展示组件（缩略色卡非点击区、图例、热力格）加按压反馈。

## 验收条件

1. 共享实现收敛后三处原手感逐位不变；`PressScaleTest` 全绿。
2. 快捷量 / 间隔 / 主题卡 / 入口 / 步进按压有缩放回弹、无水波纹；减少动态全部直显。
3. 时间线删除与展开/收起为 240ms 尺寸过渡（减少动态直变）；既有时间线测试与视觉基线（静止态）不受影响。
4. `gradlew.bat ktlintCheck build` 全绿；2.8.0 / versionCode 52 出包入 dist，归档后清理 2.6.0/2.7.0 历史包（保留 1.0.0/2.0.0/2.5.0 里程碑）。
5. 真机待验收项如实披露于版本 QA：各触点按压手感、时间线过渡流畅度。
