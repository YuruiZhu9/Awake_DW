# Awake_DW v0.3.0-alpha6 · 素材接入、文案收口与视觉层次

- 日期：2026-09-04
- 状态：进行中
- 目标：在不增加喝水工具复杂度的前提下，继续提高界面的精致感、可读性和触摸体验。

## 1. 产品边界

Awake_DW 仍然只负责喝水记录、喝水提醒、今日/历史饮水事实，以及目标、杯量、提醒时段、主题、声音和文案设置。猫咪是轻量的视觉角色；Lolita 素材只作为背景氛围和装饰层。不会恢复今日之裙、穿搭、衣橱、画廊、馆藏、收藏、解锁、奖励、连续养成或猫咪成长机制。

## 2. 本轮计划

### 2.1 文案

- 将「我的」页、提醒状态、引导、文案编辑器的说明改成自然、简洁的中文。
- 保留第一人称自用语气，但减少“轻轻叫一声”“温柔抵达”等不自然的拟人化表达。
- 早/白天/晚间的心意文案统一为可用于普通喝水反馈和猫咪气泡的短句，避免角色口吻污染普通反馈。

### 2.2 猫咪素材

- 使用 `images/cat/beforedrink.png` 作为空闲状态、`images/cat/afterdrink.png` 作为记录后的开心状态。
- 处理记录后素材的白底后再放入 APK，避免 96–112dp 组件出现整块白色背景。
- 没有第三张素材时，安静状态复用空闲图并保留低饱和处理；代码矢量仅作为资源缺失时的兜底。
- 不从来源不明的网站下载猫图。本轮不需要用户额外收集图片或资料。

### 2.3 Lolita 氛围素材

- 从 `images/Lolita` 选择绿色、玫瑰、暖金、蓝紫和哥特风格的边框素材，转为低透明度的背景装饰。
- 按主题确定性切换素材，换肤时不产生收藏、解锁或“今日内容”语义。
- 使用乘法混合和中心留白，保证进度环、按钮、统计和设置文字仍是第一信息层级。

### 2.4 主题与粒子

- 增加一个高质量的雾紫主题，作为外观选项，不改变提醒和记录逻辑。
- 粒子场增加安静/标准密度参数：首页、设置和引导保持安静，统计和开屏保留标准密度。
- 减少动态时，背景、粒子、猫咪呼吸和装饰变化全部静止；不影响核心记录和提醒。

## 3. 验收标准

- 「提醒」副标题和状态行一眼能理解，不出现机械或过度诗化措辞。
- 两张用户猫咪图片在首页 112dp 左右显示时无白色方块、无明显裁切，记录前后切换可辨识。
- Lolita 装饰只停留在页面边缘/背景，不遮挡核心信息，不新增产品流程。
- 五个固定主题色卡可读，焦糖仍保持清透棕褐，雾紫与其他主题有明显区分。
- 粒子密度随页面职责收敛，减少动态设置生效。
- `ktlintCheck`、相关测试、全量 `build` 和 debug/release APK 构建通过。
- 推送后 `main` 与 `origin/main` 同步。

## 4. 素材说明

素材由用户放在 `images/cat` 与 `images/Lolita`，本轮直接使用这些文件，不需要用户再收集图片或资料。若未来需要新增姿态、透明背景或授权不明确的外部素材，会在实现前先声明尺寸、处理方式、来源/授权和 APK 体积影响。
