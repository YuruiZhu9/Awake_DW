# 2.0.1 · 英雄区与主操作间距修正计划（2026-09-24）

> 状态：**已实施并发布 v2.0.1**。

## 问题

2.0.0 的第一版编辑部构图把紧凑环放在英雄区右侧，但主按钮仍在整个英雄行之后。结果是环上方、环下方的留白叠加，使用者需要向下寻找主操作，首屏节奏变松。

## 修正

- 紧凑环由 148dp 调整为 132dp，作为仪表而不是第二个主角。
- 英雄区改为「左侧英雄数字 + 左侧主按钮 / 右侧紧凑环」的同一版面带，主按钮不再落到环之后。
- 快捷饮量保留在英雄带下方，仍是次级路径。
- 刊头到英雄带的间距由 24dp 收至 14dp；英雄带到快捷量收至 12dp。
- 业务、文案反馈通道、猫咪常驻入口、Splash 交棒与持久化不变。

## 验收

- `EditorialHomeLayoutTest`、`ktlintCheck`、主源码编译与 Release 构建通过。
- 360dp 下「今日饮水 / 记一杯 / 紧凑环」同一首屏区带可见。
- 真机复核：环上下留白、按钮可达性、环心引文可读性、大字体与减少动态。
