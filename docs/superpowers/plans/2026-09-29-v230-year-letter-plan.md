# 2.3.0 立项：年度信纸（候选 D，2026-09-29）

> 方向依据：`docs/design/2026-09-29-future-directions-research.md` §4（Wrapped 模式的克制化）。
> 使用者 2026-09-29 指示沿既定方向队列继续优化、稍后统一验收。一步一发版，versionCode 47。

## 1. 设计决策

- **形态**：统计页页尾新增「年度信纸」一节（今日记录之后）——用既有引文 + 落款的排版语言（衬线正文、小字落款），陈述当年的三个事实：全年总量、杯数、最常饮水的时段。不新增页面、不改导航。
- **数据**：`WaterRepository.recentRecords(daysBack = 今天是一年中的第几天)` 恰好覆盖 1 月 1 日至今（与 2.1.0 月热力复用 `weekBars` 同一思路），一次调用同时算出总量、杯数与时段分布；`ArchiveMath.yearLetter` 纯函数聚合，时段沿用 `TimeSlots`（早/白天/晚），并列时取固定顺序（早→白天→晚）的第一个。
- **文案**（现代白话、零文言、无第二/三人称、只陈述事实、无成就与对比措辞——D10 边界）：
  - 正文两行：`{year} 年，共记下 {总量}、{杯数} 杯。`（总量沿用 `StatsMath.weekTotalLabel`：满 1L 用一位小数升，不足保留毫升）；`喝得最多的时段是{早|白天|晚}。`
  - 落款一行小字：`新的一年，也按时喝水。`
- **空态静默**：当年零记录时整节不出现（与时段节律同一纪律）。
- **语义**：信纸为普通文本节点顺序朗读，不做整体摘要合并。

## 2. 验收条件

1. `ArchiveMathTest` 新增：聚合总量/杯数、最常时段拾取、并列取固定顺序、零记录返回 null、`letterLines` 升与毫升两种格式。
2. `StatsViewModelTest` 新增：有记录年信纸字段就位、空库整节静默。
3. 全仓库强制 `ktlintCheck build --rerun-tasks` 全绿；发布 versionCode 47 / versionName 2.3.0，APK + SHA256SUMS 入 `dist/` 并随提交推送。
