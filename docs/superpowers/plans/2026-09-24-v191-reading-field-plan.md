# 1.9.1 · 阅读场与视觉稳态计划（2026-09-24）

> 状态：**已实施并发布 v1.9.1**。本计划是 1.9.0 之后的第一轮安全美化，不提前落地尚未确认的 2.0 结构性方向。
>
> 一句话决策：**先不换骨架，先把「背景是氛围、内容是主角」做成一个可复用的阅读场；下一阶段再以「编辑部式正脸」作为 2.0 结构突破候选。**

## 1. 问题判断

当前八主题已经具备背景、分层场景、浮空图表和留白，但真机/原生渲染复查仍有三个共同问题：

1. 插画与中景素材在内容区后的存在感偏强，首页环心、统计数值和设置行会被背景纹理抢走。
2. 轻主题与深主题的内容可读性依赖各自素材运气，页面之间没有统一的「阅读场」层。
3. 1.5–1.9 已经完成大量参数级抛光；在没有确认新骨架前继续改字号、间距或装饰收益递减。

参考 `docs/design/mobbin-reference-notes.md` 提炼的成熟模式，本轮只借用“内容与画布分层、靠表面明度而非厚重边框建立层级”，不复制任何第三方界面或素材。

## 2. 本轮设计决策（1.9.1）

### 2.1 新增共享 `ReadingField`

- 放置：主题背景与页面内容之间；不进入语义树，不持有业务状态。
- 形态：主题明暗自适应的宽幅径向/纵向柔和遮罩，中心透明度略高，向边缘渐隐；不是卡片、不是画框、不是新的边框系统。
- 目的：让文字、进度环、统计图与设置控件形成稳定的“纸面阅读区”，同时保留边缘插画的呼吸感。
- 颜色：浅色主题取白色纸面，深色主题取黑色墨面；透明度固定在克制范围内，不根据记录结果变化。
- 动效：静止；减少动态模式下行为完全一致；不引入随机、网络、模糊滤镜或 3D。
- 接入：首页、统计、我的、引导四个页面统一使用，避免页面间出现不同的对比度语言。

### 2.2 明确不动

饮水业务、记录/撤回与删除流程、持久化键、导航栈、权限、常驻猫咪提示、三条文字反馈通道、八主题色板与现有本地素材均不改变。

## 3. 自动化与验收

### 自动化

- 新增 `ReadingFieldTest`：验证八主题都得到合法、确定性的透明度策略，深浅主题方向不反转，透明度处于设计上限内。
- 继续运行首页、统计、设置视觉复查测试；截图只作原生渲染诊断，不替代真机验收。
- 运行 `git diff --check`、相关单测、`ktlintCheck` 与完整 `build`。

### 真机待验收

- [ ] 360dp / 411dp：首页环心与“记一杯”在八主题下是否更稳、更少被背景抢焦。
- [ ] 统计页数字、周图和时间线的可读性；大字体 1.5× / 2× 是否仍自然滚动、不遮挡。
- [ ] 设置页浅色主题的纸面是否仍透气，深色主题是否没有被压成一块黑板。
- [ ] 减少动态模式与 API 26–32 回退路径的静止观感和帧率。

## 4. 后续美化路线（2.0+，先保留确认闸门）

### 2.0 候选：编辑部式首页（推荐的结构突破）

依据 `docs/design/v2.0-breakthrough-directions.md` 方向一：日期刊头 + 大号衬线饮水数字成为版面主角，环退为精密仪表，猫与引文保留原有位置语义但进入页边注/署名层级。该方向会改变首页构图，必须在单独的用户确认后实施，不能由本轮的“阅读场”默认授权。

### 2.1 候选：活的画布

在现有三层场景之上做滚动视差与场景呼吸；优先复用既有确定性绘制与 `rememberSceneSpec()`，真机帧率不达标就不进入发布。

### 2.2 候选：统计档案化

沿用 Mobbin 采集得到的 hero 数值、浮空图表、发丝统计格，增加月历热力条与时段节律图；只呈现事实，不加入积分、连击或奖励语义。
