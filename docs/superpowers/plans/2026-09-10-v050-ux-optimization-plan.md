- 首页事实摘要等宽居中基线（visual-baseline §8）、导航结构、权限申请、持久化键名：**一律不动**。
- 不新增养成／收藏／奖励／连续天数展示等 §8 明确排除项。
- 不引入新素材、不新增网络能力、不引入字体文件。

## 3. 用户已确认的取舍（2026-09-10）

1. **文案架构**：拆出独立短句池。心意文案库收窄为「首页问候 ＋ 提醒通知正文」的长句（仍为可编辑的 108 句）；打卡确认与猫语改用内置短句池，各自独立去重。

## 4. 设计决策

### 4.1 语料分层

| 用途 | 来源 | 可编辑 | 形态 | 去重键 |
| --- | --- | --- | --- | --- |
| 首页问候语 | 心意文案库（108 句） | 是 | 长句 12–18 字 | `MORNING` / `DAY` / `EVENING` |
| 提醒通知正文 | 心意文案库（108 句） | 是 | 同上 | 同上 |
| 打卡确认 | 内置短句池 `ShortCopies.praise*` | 否 | 6–12 字 | `PRAISE_MORNING` … |
| 猫咪回应 | 内置短句池 `ShortCopies.cat*` | 否 | 5–12 字 | `CAT_MORNING` … |

- 短句池不进 DataStore、不进编辑器，与粒子／花边同属「装饰性微文案」层级；文案库 JSON 结构与键名保持不变，向后兼容。
- 去重键沿用 `"<key>\|<句子>"` 存储格式，新增键前缀不与旧数据冲突；旧键值继续被读取。
- 文案池润色准则：第一人称「我」；开句可独立成立、有开场感；**不写成完成态叙述**（作为问候出现在记录之前不能自相矛盾）；不使用命令句、承诺句、书面语「饮水」；全局无重复句、无 `\|`。

### 4.2 反馈编排（三条通道物理分离）

| 通道 | 落点 | 时长 | 说明 |
| --- | --- | --- | --- |
| 打卡确认 | **环心**（替换「今日已喝」小字一行） | 1.4s | 零布局位移，确认出现在用户刚看着的位置 |
| 达标横幅 | 环下，`AnimatedVisibility` 展开／收起 | 2.5s | 有动画的展开不算「跳动」；复用缎带语言 |
| 猫咪回应 | 猫语气泡（原位置） | 2.0s | 只承载猫语，不再与夸夸语抢格子 |

节奏：0s 三通道同时起；1.4s 环心复位；2.0s 猫语收；2.5s 横幅收。

### 4.3 记录纠错

- `WaterRepository.delete(recordId: Long)` → DAO `DELETE WHERE id = :id`；删除后 `changes` 行数流自动触发重算，无需额外刷新。
- 首页「最近一杯」长按撤回：撤回的是当日**最后一条**记录，撤回前弹确认。
- 统计页时间线每条长按可删，撤回前弹确认。
- `celebrated_day_key` 不做回滚：撤回后再达标不重复庆祝，避免「撤回—记录」循环刷庆祝。
