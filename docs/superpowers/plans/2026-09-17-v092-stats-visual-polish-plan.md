# 0.9.2 · 统计页美观性抛光（2026-09-17）

使用者反馈：统计页「不好看」。基于现有视觉 review 截图（`stats-emerald` / `stats-target-met` / `stats-empty` / `stats-large-chart`）诊断，三个病灶，全部是呈现层问题——不动任何业务、语义键、删除流程与时间线行结构。

## 病灶诊断

1. **「今日饮水」面板是一堵文字表格墙**：M3 `LinearProgressIndicator` 自带终点圆点（stop indicator）——空态下轨道右端悬着一颗点像「已满」，平时整条读起来像滑块；四格事实（记录次数/平均间隔/近七日合计/近七日达标）左对齐两行参差排布，无分隔无节奏，与首页摘要「等宽居中」（0.4.0 规则）不成家族；面板标题是裸 `Text`，而另两块面板走 `PanelTitle` 饰线轨——同一屏两种面板语言。
2. **图表面板顶部压着两行工具文字**：「2026-09-08 · 1250ml」＋「虚线为目标 1600ml · 点柱查看」——说明书式散文压在图上，杀纸面氛围。
3. **空态左对齐**：「暂无饮水数据」孤零零靠左，与时间线空态的居中安静不一致。

## 设计决策（全部沿用既有语言，不发明新装饰）

- **三块面板统一 `PanelTitle` 饰线轨**：「今日饮水」改走 `PaperPanel(title = …)`，与「近七日」「今日记录」同语言。
- **自定义细轨进度替代 M3 进度条**：3dp 圆角细轨（`ringTrack`）+ 主题主色圆角填充 + 进度头一颗小珠点（珍珠语言，呼应 PanelTitle 圆点）；进度≈0 时不画珠点，终点永远没有 M3 那颗悬空圆点。语义等价：`contentDescription` 由纯函数给出（「今日已达标」或「今日进度 N%」）。
- **达标状态右置提权**：「每日目标 1600ml」居左小字，达标时右侧主色「已达成」——当日最重要的事实不再混在灰字里（仍只有文字确认，无徽章/奖励语义，D10 边界不变）。
- **事实四格改等宽居中 + 发丝分隔**：2×2 单元格居中、格间用 `laceColor` 发丝线（横一 + 竖一）——编辑排印的「纸面小表格」，与首页摘要等宽居中规则同族。`StatsFact` 的合并语义（「标签 值」）保持不变。
- **图表面板读数一行化**：左「9月8日 · 1250ml」（`dayReadout` 纯函数把 dayKey 转成中文月日；柱语义同步换友好日期），右「┄ 目标 1600ml」图例（14dp 虚线小样 + 小字）；「点柱查看」删除——点选有高亮与读数即时反馈，不是隐藏手势，不需要说明书。
- **空态居中**：「暂无饮水数据」与时间线空态同款居中。

## 验收条件

自动化（先写先改）：
1. `StatsMathTest` 新增 `dayReadout`（正常/异常原样返回）与 `todayProgressLabel`（达标/部分/零）断言。
2. `StatsVisualReviewTest` 读数断言改新格式（「9月4日 · 1000ml」），柱语义断言同步；视觉截图全部重拍并人工复查。
3. `StatsWeekSummaryLayoutTest`（0.9.1）原断言不动、保持绿——证明四格重排没有破坏合并语义。

真机待验收（随版披露，非阻塞）：新细轨进度与珠点在八主题下的对比度；发丝分隔在大字体 2×下的折行；图例小样的可读性。
