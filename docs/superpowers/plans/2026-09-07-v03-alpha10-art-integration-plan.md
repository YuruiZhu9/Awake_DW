# v0.3.0-alpha10 · 用户素材接入与主题艺术细节

## 产品边界
仍是喝水记录与提醒应用。素材、粒子和边饰不对应收藏、解锁、奖励、养成或每日内容；不增加新操作入口。

## 素材评估
- 薄巧：941×1672 完整背景，奶白蕾丝、可可丝带、杯碟与薄荷花饰；保留完整边框，中央图案降存在感。
- 黑白双面：941×1672 黑色帷幔/白色圣职混合背景，作为明暗材质参考；不把双面强行套到两个独立主题，也不增加第三个混合主题。
- 哥特：1024×1536 透明元素图。取黑玫瑰、窗棂与垂饰重新排成边角构图，保留中央留白；不将整张素材表原样铺在数据后。
- 圣职：1024×1536 透明边框。保留原始圣徽、珍珠链和白蕾丝，铺在冷白纸面上；不再使用无图占位。

## 实施方案
1. 原图原样保存在 images；新增可复现的 PowerShell/System.Drawing 素材处理脚本，仅输出 app/assets 的压缩衍生图。
2. 三套背景独立文件、明暗混合策略与透明度；新增素材按边缘展示、中心遮罩处理，不再统一反相或全屏压到 18%。图片按目标区域适配，窄屏尽量保留两侧边框；横屏不拉伸。
3. 主题粒子按艺术语言区分：薄巧珍珠、哥特小银芒、圣职柔光花瓣；粒子主要在侧缘漂浮、中心减弱，维持安静密度与现有减少动态开关。
4. 分隔线与环顶结饰主题化：薄巧丝带与细针脚；哥特尖拱/菱形银饰；圣职银线与小光芒。不重复在同屏堆大量十字、花朵、蝴蝶结。
5. 统计/设置纸面提高遮蔽度，确保新背景不穿透正文、表单和图表；选项卡预览展示真实主题素材，而不是仅有色块。
6. 饮水确认保持快速反馈，爆发粒子缩小并跟随主题形态，不遮挡杯量；不延迟记录，不添加确认对话框。

## 验证
- 背景文件映射、尺寸与可复现资产检查；三套正式资源实际存在且解码成功。
- 主题图案/粒子映射、中心淡出和半径上限测试；减少动态模式不启动新循环。
- 首页三主题原生渲染图，360dp/大字体按钮和猫可达；设置真实主题缩略图选择与大字体测试；旧记录、防抖、存储测试保留。
- ktlintCheck / build（含 Debug 与 Release）、APK 版本和验签、工作区检查；发布 alpha10，versionCode 15。
- 无真机连接时明确标记：原生渲染不是中端设备流畅度验收。记录仍待真机观察的项目。

## 材料与后续
本轮无需用户额外收集素材，也不下载外部图片。专属粒子与代码绘制细线仅辅助已有素材，不替代用户图像。
下一轮根据安装效果调整边缘图案亮度、卡片透光和字体密度；完整导航、低亮度 OLED 与动效帧率仍需真机观察。

## 渲染迭代补充
- 竖屏等比铺满消除图片侧缘硬边；统计、快捷按钮与设置面板提高到 94% 底色，保证读取。
- 位图缓存上限 16MiB，按 AssetManager 与路径隔离，首页与主题缩略图复用实际解码结果；缺失/损坏资源不缓存。
- 预览快照使用相同生产解码路径提前加载真实图片，再进行单选和像素输出，异步装载本身由资产加载测试覆盖。
