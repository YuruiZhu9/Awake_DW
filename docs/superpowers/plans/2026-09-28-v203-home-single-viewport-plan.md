# 2.0.3 · 首页一屏收敛计划（2026-09-28）

> 状态：实施中。触发：使用者反馈 2.0.2 首页「长度远远超过手机页面」，整页须显著收短。这是**高度收敛**，不是新风格探索；编辑部式构图（基线 §15/§16）与全部语义边界不变。

## 1. 问题复盘（按 360dp 宽、fontScale 1.0 实测推算）

首页内容列自上而下：

| 段 | 高度 |
| --- | --- |
| 顶部留白 | 22dp |
| 刊头（日期 + 问候，段内间距 7dp） | ~55dp |
| 刊头→英雄区间距 | 14dp |
| 英雄行（132dp 环为最高者） | 132dp |
| 英雄行→主按钮 | 10dp |
| 主按钮 | 56dp |
| 主按钮→快捷量 | 10dp |
| 快捷量（48dp 触控下限） | 48dp |
| 快捷量→猫栏 | 14dp |
| **猫栏（提示胶囊 48dp 与 84dp 猫立绘叠成两行）** | **~132dp** |
| 猫栏→事实条 | 18dp |
| 事实条 | ~59dp |
| 撤回说明（有记录时） | ~22dp |
| 底部呼吸 | 24dp |
| **合计（有一条记录）** | **~616dp** |

常见手机扣除状态栏、底导航与手势区后的有效内容视口约 620–680dp，16:9 小屏不足 530dp；1.3× 字体下再涨约 60–80dp。结果是任何机型都在滚，小屏大字体滚过一整屏——使用者感知为「长度远超手机页面」。

最大的可避免块是**猫栏**：常驻提示胶囊（48dp 触控下限）竖叠在 84dp 猫立绘上方，为一个单行页边注付出 132dp。

## 2. 修正方案

1. **猫栏单行化（约 −40dp）**：提示胶囊从猫立绘上方移入左侧回应列顶部（居左），猫语气泡／无回应纸饰排其下；猫立绘留在右侧、垂直居中。栏高 132dp → 约 92dp。常驻入口仍常驻可点（基线 §3），气泡仍只承载猫语，长回应仍在左列左对齐自然换行——三条文字通道物理分区不变。
2. **节奏收紧（约 −20dp）**：刊头段内 7→4dp；刊头→英雄行 14→10dp（SplashMorph `RING_CENTER_STACK_DP` 的 +10dp 估算随之变准，开屏零改动）；英雄行→主按钮保持 10dp（几何断言区间内）；主按钮→快捷量 10→8dp；快捷量→猫栏 14→10dp；猫栏→事实条 18→12dp；说明行前 8→6dp；底部呼吸 24→20dp。
3. **不动**：132dp 环与开屏常量、业务、持久化、导航、权限、主题素材、三通道分工、文本不截断、48dp 触控下限。

收敛后推算：一条记录约 553dp（1.0×）、约 620–635dp（1.3×）——常见手机有效内容视口一屏放下；16:9 极小屏仍允许滚动（基线 §5 只要求主操作首屏可见）。

## 3. 自动化验收

- 新增几何断言（360dp × 640dp、fontScale 1.0、有一条今日记录）：事实条与撤回说明整页落在一屏内（末节点 bottom ≤ 根高），页面无须滚动即可读完。
- 新增猫栏高度断言：猫栏实测高度 ≤ 100dp，防止提示胶囊再次竖叠回猫上方。
- 既有守护全数保持：520dp × 1.3× 有效视口五项几何断言、猫盒与按钮/胶囊 bounding box 互斥（静止 + 滚到底）、长回应不压猫与后续动作、八主题首屏元素在场。
- 原生截图重拍仅作诊断；真机仍是最终视觉闸门。
