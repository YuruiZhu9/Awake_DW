# 2.2.0 追加立项：统计闪退修复 + 首页减法（2026-09-29）

> 与已立项的「环即把手」计划（`2026-09-29-v220-ring-drag-plan.md`）合入同一个 2.2.0/versionCode 46 发布。
> 起因是真机验收的三条反馈：首页仍然超长、统计页点击闪退、整体 UI 进步感不足。

## 1. 统计页闪退（P0，已修复）

**根因**：`MonthHeatmap` 图例行取梯度色用了 `HEAT_ALPHAS[index + 1]`，第 5 块色样下标越界
（`Index 5 out of bounds for length 5`）。热力图只在 `monthCells` 非空时组装，而既有
`StatsVisualReviewTest` 的填充态用旧四参构造（monthCells 默认空），**新组件从未被任何测试渲染过**；
真机本月数据恒非空 → 2.1.0 对每个用户打开统计页必崩。

**修复**：`HEAT_ALPHAS[index]`（第 1–4 块对应 1–4 档透明度，与热力格同源）。

**防再犯**：新增 `StatsArchiveRenderTest`——月历热力与节律条**填满数据**的整页渲染测试，
补上这次暴露的渲染覆盖盲区。

## 2. 首页减法（本计划的主体）

**为什么 2.0.3 之后还是长**：2.0.3 的一屏在 h640dp **测试视口**成立（无底栏、无系统导航）；
真机内容视口还要扣掉状态栏、系统导航与底栏（约 -110dp）。当前整页 ~547dp（有记录时），
在中小屏上必然出滚动。逐版微调间距救不了，**必须撤内容**。

**与 1.5 早期的对比**（用户建议的回溯）：1.5.0 首页没有刊头侧的英雄数值行，事实摘要
（今日 N 杯 / 最近一杯 / 平均间隔）当时已经存在，但统计页同样有这些事实——
后来首页与统计页双份维护，首页越来越像报表。

### 减法决策

| 撤除项 | 理由 | 去向 |
| - | --- | --- |
| `BadgesRow`（今日/最近一杯/平均间隔三格） | 统计页 1.5.0 起有同款事实格（记录次数/平均间隔），首页 hero 已有总量与目标差；首页不该出现第二份报表 | 统计页 |
| 撤回提示行（「长按最近一杯…」）+ 确认对话框 | 随事实条撤出；统计页时间线本就有带确认步骤的逐条删除 | 统计页 |
| 猫立绘 84→64dp、整栏下限 92→72dp | 常驻提示保留（`CatRailLayoutTest` 不变量不动：回应期间提示仍可见可点），只是整栏收紧 | 原地 |

- `revertLatestCup` 与撤回回执链路**保留在 HomeViewModel**（3 例单测继续守护），本轮只撤 UI 入口；
  后续版本若统计页要挂「最近一杯快捷撤回」可直接复用。
- 预期效果：整页 ~547dp → ~430dp（fontScale 1.0），大字体 ~460dp。

### 验收条件（比 2.0.3 收紧一档）

1. `HomeScreenOverflowTest`：360×520dp、fontScale 1.3（≈中小屏真机有效内容视口）整页无滚动读完。
2. 360×640dp、fontScale 1.0 有记录态一屏读完（沿用 2.0.3 断言，末元素改为猫栏）。
3. 全模块测试 + 全仓库强制 `ktlintCheck build --rerun-tasks` 绿。
