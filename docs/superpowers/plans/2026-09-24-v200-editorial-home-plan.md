# 2.0.0 · 首页「信纸的正脸」计划（2026-09-24）

> 状态：**已实施并发布 v2.0.0**。
>
> 本轮不再做参数级微调，直接采用 v2.0 候选方向一：**编辑部式首页**。第一眼必须能看出构图换了，而不是换了一层颜色。

## 1. 用户反馈与决策

使用者明确反馈：1.9.x 仍像在原有框架上修修补补，UI 基本没有变化，不够好看。

因此本轮改变首页的**构图与信息层级**：

- 日期刊头 + 问候语成为页面开头，而不是居中的小标题。
- 今日饮水总量移出环心，成为第一视觉主角（display 级衬线数字）。
- 进度环缩为右侧精密仪表，只承担进度与环心反馈，不再承载整块首页信息。
- 记录操作紧随英雄区，猫咪仍常驻可点，但退为页边注／陪伴层。
- 事实摘要保留在页面下部，语义与撤回长按不变。

## 2. 不变红线

- 饮水业务、记录/撤回、防抖、持久化键、导航、权限不变。
- 打卡确认仍在环心，达标横幅仍在环下，猫语仍在猫咪气泡；三条通道不合并。
- 常驻「点击我试试~」入口不隐藏。
- 不新增网络素材；不依赖新图即可验证结构。
- 不做积分、连击、奖励或养成语义。
- 大字体自然撑高/滚动，不截断文本。

## 3. 实施范围

### 3.1 首页结构

旧结构：

`问候 → 花边 → 大环（数字在环心） → 猫 → 记录按钮 → 事实条`

新结构：

`日期刊头/问候 → 英雄数字 + 小环仪表 → 达标确认 → 记录动作 → 猫咪页边注 → 事实条`

### 3.2 组件策略

- 新增 `EditorialHomeMasthead`、`EditorialHeroValue`、紧凑环心内容；页面组合留在 `:feature:home`。
- 复用 `ProgressRing`、`HomeActionDeck`、`CatRail`、`BadgesRow` 和现有场景背景。
- Splash 交棒同步新的环尺寸与落点，避免开屏到首页再次跳变。

## 4. 自动化验收

- 首页交互测试仍能找到并点击「记一杯」，连续点击防抖与记录结果不变。
- 首页视觉回归新增英雄数字、日期刊头、紧凑环、主操作顺序的语义断言。
- 大字体/窄屏下按钮、猫咪、事实条仍可滚动到达，且不互相覆盖。
- `RingNoteRenderTest` 继续守住环心默认文案与打卡引文通道。
- `ktlintCheck`、相关单测、Release 构建通过。

## 5. 真机闸门

- [ ] 360dp 首页第一眼是否明显区别于 1.9.1，而不是仅仅更亮/更淡。
- [ ] 英雄数字是否足够成为主角，同时不显得像统计页复制品。
- [ ] 小环在八主题下是否像精密仪表，而不是缩小后变得寒酸。
- [ ] 主按钮是否更快可达；猫咪与常驻入口仍自然、不抢主操作。
- [ ] 1.5× / 2× 字体、减少动态、API 26–32 回退路径。
