# Awake_DW v0.3.0-alpha7 · 首页布局与背景可见度收口

- 日期：2026-09-07
- 状态：代码实现与自动化验证完成，真机视觉验收待执行
- 目标：在不增加产品复杂度的前提下，解决猫咪遮挡事实信息的问题，并继续收口首页的布局、按钮和背景氛围。

## 本轮边界

Awake_DW 仍然只负责喝水记录、喝水提醒和饮水事实展示。猫咪与 Lolita 素材只服务于视觉表达，不增加收藏、解锁、养成、画廊或奖励机制。

## 实施方向

1. 猫咪改为跟随首页内容流，放在事实统计行之后的独立收尾带；猫语气泡向上展开，避免遮挡杯数、最近一杯和平均间隔。
2. Lolita 背景图轻微提高可见度，并减少中央洗染的覆盖强度，保持核心信息清晰。
3. 快捷饮量控件改为等宽布局，优化小屏和大屏下的按钮节奏。
4. 继续保持 Quiet 粒子、减少动态适配和现有按压/入场动画，不扩展产品机制。

## 素材声明

本轮不需要用户再收集图片或资料，继续使用用户已提供的 `images/cat` 与 `images/Lolita` 素材。
