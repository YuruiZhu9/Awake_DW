# 0.4.0 · 首页摘要等宽排版

## 用户确认与范围
- 2026-09-08：用户要求首页「今日／最近一杯／平均间隔」占满左右可用空间，并以 0.4.0 发布、推送远端。
- 原因：FlowRow 按内容宽度从左排列，剩余空间留在右侧。
- 改为满宽 Row，各摘要 weight(1f)，栏内标签和数值居中；保留纸面、花边、颜色和主操作层级。
- 无最近一杯数据时继续不显示该事实，但其余两栏均分宽度；不改变数据语义。
- 长文本与大字体自然换行，顶部对齐、不截断、不设置固定高度，不引入新装饰。

## 验收
- 新增摘要专用回归：三栏等宽／左右对称、空态两栏等宽、320dp／2× 字体长值不溢出，以及八主题诊断图。
- 运行首页与设计系统测试、ktlintCheck、完整 build；生成并复核 Debug／Release 的包名、版本、签名、SHA-256。
- 提交划分：设计规则与计划、布局与测试、版本与安装包；仅将验证后的安装包推送到既有 origin/main。
- 真机待验收项单独记录，不因用户选择 0.4.0 编号便宣称已完成稳定性验证。
