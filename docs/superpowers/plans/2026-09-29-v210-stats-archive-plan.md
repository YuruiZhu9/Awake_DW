# 2.1.0 · 统计页「档案化」计划（2026-09-29）

> 状态：实施中。方向出处：`docs/design/2026-09-29-future-directions-research.md` 候选 A（使用者已确认「直接开始实现」）；对应 roadmap 长程美学路线预排的「统计纵深」。参照样本：Zero 月历热力、Slopes 堆叠分布条（mobbin 匿名趋势区，2026-09-29 采集）。

## 1. 目标与非目标

- 目标：统计页从「摘要」变「档案」——在既有近七日柱图与今日时间线之间新增两节**纯事实**内容：**本月热力**（月历网格，深浅表达每日距目标的完成度，圈出今天）与**时段节律**（近七日早/白天/晚构成，一条堆叠分布条 + 图例行）。
- 非目标：不改业务写入路径、持久化键、导航、权限、首页、引导；不加奖励/连续/成就语义（D10）；不动既有 hero、指标格、周柱图、时间线的结构与风格（1.5.0/0.9.2 基线保持）。

## 2. 设计决策

1. **时段沿用既有分类学**：节律分桶复用 `core:common` 的 `TimeSlots`（早 6–10 / 白天 11–17 / 晚 其余）——与心意文案库、问候语的时段语言完全一致，不新增第四个时段；图例文案「早 / 白天 / 晚」为现代白话。
2. **热力梯度用主题主色透明度阶梯**（0 / 0.20 / 0.42 / 0.66 / 1.0 五档），不引入新颜色；`>=0.66` 档改用 `onPrimarySurface` 保证数字可读。达标日（最高档）就是「满」，不另画标记。今天用主色描边圈出；未到来的日期淡显、不填色（不是虚构数据，只是留空）。
3. **堆叠条单色渐层**：早/白天/晚 = 主色 1.0 / 0.55 / 0.28 三段，段间 2dp 纸色缝隙；图例行 = 色点 + 标签 + 右对齐毫升数（Slopes 式），不放百分比（毫升是事实，占比是评价）。
4. **空态纪律**：近七日零记录时**时段节律整节静默**（标签一起隐藏）；月历热力始终呈现（档案骨架，全空即全空）。图例用「少 □□□□■ 多」小样，不写说明书散文（0.9.2 规则）。
5. **语义等价**：月历容器 `clearAndSetSemantics` 摘要「{n}月：有记录 x 天，达标 y 天」——TalkBack 不逐格走 31 个数字；堆叠条 contentDescription「近七日时段分布：早 a ml，白天 b ml，晚 c ml」。
6. **新增唯一的数据读路径**：`WaterRepository.recentRecords(daysBack)`（含今天的最近 N 天记录，时间升序，只读）——节律需要带时间戳的原始记录，`weekBars` 只有日总量。Room 实现用既有「day_key_local 字典序即时间序」约定；月热力完全复用 `weekBars(daysBack = 今天几号)`，零新增查询。
7. 纯函数进 `StatsMath`（月历网格 / 热力档位 / 节律聚合 / 两条摘要），保持本页既有先例；时区转换在纯函数签名内显式接收 `ZoneId`。

## 3. 自动化验收

- `StatsMathTest`：月历网格（周一首行偏移、今/未来标记、总量映射）、热力档位边界、节律聚合（含 23 点归晚）、两条摘要文案。
- `StatsViewModelTest`：新增用例——铺多日记录后 `monthCells` 标记今天且未来格为空、`rhythm` 按时段聚合、零记录时节律为全零切片。
- `RoomWaterRepositoryTest`：`recentRecords` 窗口与升序（含跨日边界）。
- 既有几何/视觉回归全数保持；`ktlintCheck build` 全绿。
- 真机待验收（版本 QA 披露）：两节新内容在 360/411dp、1.3×/2× 字体下的可读性；八主题下热力梯度与堆叠条对比度；减少动态。
