# Awake_DW v0.3.0-alpha8 • 首页信息层级与黑白哥特主题

- 日期：2026-09-07
- 状态：代码实现与自动化验证进行中
- 目标：减少首页主环和猫咪对内容的压迫感，新增黑白哥特主题，并把主操作按钮收口为更稳定、更清晰的视觉组件。

## 本轮方向

1. 猫咪在进度环之后以紧凑 rail 展示，保留互动但不把页面末尾拉得过长。
2. 主进度环缩小到 196dp，环心读数降低视觉重量。
3. 新增黑白哥特主题：暗黑背景、冷白银灰强调、暗银蕾丝和哥特 Lolita 边框。
4. 主按钮改为 56dp 圆角矩形，快捷按钮等宽；保留触摸反馈、触感和减少动态适配。
5. 浅色主题下提高 Lolita 边缘装饰可见度，降低中央洗染遮盖。

## 产品边界

仍然只负责喝水记录、提醒和饮水事实。猫咪、粒子、Lolita 素材和主题只服务于视觉，不增加收藏、解锁、养成、奖励或游戏流程。
