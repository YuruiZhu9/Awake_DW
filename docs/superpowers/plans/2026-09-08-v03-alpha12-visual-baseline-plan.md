# alpha12 · 全主题蕾丝与视觉基线固化

## 设计决定（2026-09-08）
- 延续 alpha11 排布，不重做品牌、主题配色、素材与功能。装饰服务喝水记录。
- 用户明确修订：猫咪「点击我试试~」常驻；不因摸猫、喝水回应、回应消失而隐藏，气泡与猫共用 onPet。
- 哥特、圣职、薄巧保留专属图框；另外五主题增加 code-native 主题色边缘蕾丝，不替换已有图片，不增加网络或位图依赖。
- 花边限制在侧缘与角部；中央保留阅读区；分隔线统一为细缝线与小结饰。
- 全主题粒子按珍珠／花瓣／银光区分；沿用确定性轨迹、低密度与减少动态机制，中央降透明度。

## 实施顺序
1. 更新需求记录与常驻提示回归测试。
2. 在 core:designsystem 增加共享主题花边策略与绘制，保留三款专属图框。
3. 调整首页气泡、主题分隔及粒子；不改业务与持久化键。
4. 补全主题覆盖测试、窄屏大字测试与截图复核。
5. 固化 docs/design/visual-baseline.md、根 AGENTS.md、rules.md 和本轮 QA。

## 验收与后续
- 自动化验证记录见本轮 QA；未执行项必须明确待验收，不把构建通过等同于真机观感通过。
- 后续优先：真机字体 1.5×/2×、低端机帧率、横屏与主题切换复核；不以“优化”为由撤掉花边、替换主题、隐藏猫提示。
- 本轮不改饮水逻辑、导航、权限、主题存储键；发布签名沿用项目现有配置。
- alpha12 发布后，本 plan 与 `docs/design/visual-baseline.md` 作为后续版本的设计指导，不得回退已确认的视觉约束。
