# Awake_DW v0.3.0-alpha5 · 布局生态与日常操作体验收口

- 日期：2026-09-04
- 状态：代码实现完成，真机视觉验收待执行
- 目标：继续提高 app 的精致感与可用性，但不增加产品机制。

## 1. 产品边界

Awake_DW 继续只负责喝水记录、喝水提醒、饮水事实统计，以及目标、杯量、提醒时段、主题、声音和文案设置。不会恢复今日之裙、穿搭、衣橱、画廊、馆藏、收藏、解锁、奖励、连续养成或猫咪成长机制。

## 2. 本轮视觉与体验方向

### 2.1 快捷饮量

- 小口/满杯变成等宽、48dp 级的轻量操作控件；
- 加入小水滴识别，让动作与喝水任务建立更自然的视觉联系；
- 仍然是现有记录入口，不引入额外状态或新的产品流程。

### 2.2 统计事实

- 今日概览补充总饮水量，使统计页第一层信息可以同时回答「喝了多少、几杯、间隔多久」；
- 今日时间线增加低透明连接线，提升多条记录的阅读连续性；
- 所有信息仍然是事实呈现，不表达奖励、坚持或成长。

### 2.3 设置触摸体验

- 试发提醒、文案分组、恢复默认和新增句子采用更完整的触摸区域；
- 视觉上保持文字轻量，触摸区域不以扩大色块制造噪音；
- 兼顾窄屏、字体放大和 TalkBack 的可发现性。

### 2.4 首页布局安全

- 48dp 快捷控件变高后重新校正滚动到底态的底部留白；
- 猫咪仍是底部轻量视觉角色，不与主操作组争夺空间；
- 保持原有窄屏 bounding-box 几何守护测试。

## 3. 外部素材声明

本轮不需要用户额外收集图片或资料。继续使用 Compose 原生控件、代码矢量、主题色、纸面渐变、蕾丝和描金 token。

如果之后决定引入真实手绘/水彩猫咪或背景素材，将在实现前单独声明：图片尺寸、透明背景要求、姿态/表情数量、风格参考、授权来源和 APK 体积预算。也可以由用户提供参考图，届时先检查裁切、透明边缘和授权信息。

## 4. 验收标准

- 快捷饮量在窄屏下等宽、可点按且不与胆大王相交；
- 统计页今日概览能清楚显示总量、杯数和平均间隔；
- 时间线连接线轻且不影响时间/毫升数阅读；
- 设置页关键操作具备稳定触摸区域，不改变原有行为；
- 不新增持久化产品状态；
- `./gradlew ktlintCheck`、相关测试和 `./gradlew build` 全部通过（2026-09-04）；
- 生成 alpha5 debug/release APK；
- 真机视觉验收单独记录，自动化结果不替代肉眼判断。
