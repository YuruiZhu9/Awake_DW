# Awake_DW v0.3.0-alpha3 · 奶茶棕褐主题、心意文案与布偶猫再设计

- 日期：2026-09-04
- 状态：代码实现完成，真机视觉验收待执行
- 目标：继续提升应用的审美完成度，但不增加喝水工具之外的产品复杂度。

## 1. 产品边界

Awake_DW 仍然只负责：喝水记录、喝水提醒、今日/历史饮水事实，以及目标、杯量、提醒时段、主题、声音和文案设置。

本轮不加入今日之裙、穿搭、衣橱、画廊、馆藏、收藏、解锁、奖励、连续养成或猫咪成长机制。猫只作为视觉角色和轻量回应。

## 2. 本轮工作

### 2.1 焦糖奶茶主题

原主题的黄色比例过高，容易显得刺眼和陈旧。本轮重新建立为：

- 背景：清透奶油白 → 暖灰米 → 淡奶茶纸面；
- 主色：可可棕；
- 按钮：深可可棕 → 奶茶棕褐；
- 信息文字：深咖色；
- 轨道、蕾丝与粒子：低饱和灰棕；
- 主操作文字：焦糖主题使用白字，以保证按钮清晰度。

### 2.2 心意文案库成为唯一活动语料来源

每次喝水后的普通反馈和胆大王气泡均按当前早/午/晚时段，从同一套「心意文案库」中抽取。两次抽取共用同一时段去重池，避免连续重复。

旧版 `cat` JSON 字段继续保留仅用于向后兼容，不再读取为独立猫语料。

默认文案从早/午/晚各 20 句扩充为各 30 句，共 90 句；新增句子保持日常、轻柔、清爽，不引入奖励、成长或游戏暗示。

### 2.3 布偶猫再设计

当前版本仍使用 Compose 代码矢量，不依赖外部位图。重设计重点：

- 更宽的圆脸和更自然的布偶猫重点色面具；
- 中央奶油色鼻梁，避免脸部成为一整块褐色；
- 更大的蓝色眼睛和双高光；
- 耳尖、尾巴和围脖形成清晰的色彩层次；
- 蓬松尾巴采用填充轮廓，而非单一粗线；
- 固定蝴蝶结只作为 Lolita 视觉细节，不作为可变配饰或奖励。

## 3. 外部素材声明

本轮不需要用户额外收集图片或资料。当前使用代码矢量与现有主题绘制层完成验证，未引入来源不明的网络图片。

如果后续需要真实手绘/水彩角色图，请在开始实现前先确认以下资料：

1. 图片尺寸与目标密度（至少提供 1x/2x 或明确 dp 适配策略）；
2. 是否需要透明背景；
3. 角色姿态与表情数量；
4. 风格参考图与可使用范围；
5. 授权/来源信息；
6. 可接受的 APK 体积预算。

用户也可以直接提供参考图；拿到后会先做裁切、透明边缘、尺寸和授权检查，再决定是否进入 APK。

## 4. 验收标准

- 焦糖奶茶主题不再呈现大面积黄色，浅色背景与棕褐强调保持舒适对比；
- 每次成功喝水都产生一条来自当前时段心意文案库的猫交互话语；
- 设置页可以直接编辑会影响猫气泡的同一批文案；
- 90 条默认文案全部非空、无重复，最近窗口内不重复；
- 旧版带 `cat` 字段的 JSON 可以读取，但旧猫语字段不会覆盖当前时段文案；
- 布偶猫三态轮廓、重点色面具、蓝眼睛、围脖和蝴蝶结在 96dp 下保持可辨识；
- 不新增持久化产品状态；
- `./gradlew ktlintCheck`、相关测试和 `./gradlew build` 全部通过（2026-09-04）；
- 真机对焦糖主题和布偶猫最终审美仍需安装 alpha3 APK 后肉眼确认。
