# Awake_DW v0.3.0-alpha4 · 纸面层级与色卡控件视觉收口

- 日期：2026-09-04

- 目标：不增加产品机制，只继续提升日常喝水工具的美观性、层次和完成度。

## 1. 产品边界

继续保持喝水记录、喝水提醒、饮水事实统计和相关设置。不会恢复今日之裙、穿搭、衣橱、画廊、馆藏、收藏、解锁、奖励、连续养成或猫咪成长机制。

## 2. 本轮视觉方向

### 2.1 纸面信息层

- 统计页标题使用细线、珍珠和右侧留白建立编辑感；
- 设置页保留蕾丝顶饰，但让卡片更轻，避免每个区域都像厚重的 Material 表单；
- 首页操作组和统计事实区使用同一套低透明纸面语言。

### 2.2 主题色卡

- 主题选择从单一色点升级为小型横向色卡；
- 色卡同时展示主题主色与按钮亮色，焦糖主题明确呈现棕褐而非黄色；
- 选中态只增加边框与确认标记，不引入主题收集或内容解锁。

### 2.3 页面标题节奏

- 统计页和设置页增加低存在感副标题，形成标题、分隔线、内容三层节奏；
- 首页主操作组增加标准杯信息，使视觉装饰同时服务于理解，而不增加新的产品概念。

### 2.4 导航细节

- 底部导航增加细珍珠导轨，使导航与页面的 Lolita 结构装饰一致；
- 导轨不进入语义树，不改变点击区域和路由行为。

## 3. 外部素材声明

本轮不需要用户额外收集图片或资料。继续使用 Compose 原生控件、代码矢量、主题色、纸面渐变、蕾丝和描金 token。

如果之后需要把布偶猫升级为真实手绘/水彩位图，会提前声明尺寸、透明背景要求、姿态/表情数量、风格参考、授权来源和 APK 体积预算；在此之前不会引入来源不明的网上图片。

## 4. 验收标准

- 首页主操作、统计图表、设置卡片和底部导航保持清晰的视觉主次；
- 主题色卡在窄屏与大字体下不重叠、不裁切；
- 焦糖奶茶主题仍保持清透奶油纸面与舒适棕褐强调；
- 不改变饮水记录、提醒、路由、持久化和文案来源契约；
- `./gradlew ktlintCheck` 与 `./gradlew build` 通过；
- 产生 alpha4 debug/release APK；
- 真机视觉验收仍单独记录，不用自动化测试替代肉眼判断；自动化构建与测试已于 2026-09-04 通过。
