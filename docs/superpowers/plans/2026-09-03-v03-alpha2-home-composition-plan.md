# Awake_DW v0.3.0-alpha2 · 首页构图与视觉细化计划

- 日期：2026-09-03
- 状态：执行中
- 目标：在不增加产品机制的前提下，让首页更快读懂、更容易完成一次饮水记录，同时让 Lolita 细节成为结构装饰而不是功能负担。

## 1. 产品边界

Awake_DW 仍然只是喝水记录与提醒工具：记录喝水、提醒喝水、查看今日/历史饮水事实，以及目标、杯量、提醒时段、主题、声音和文案设置。

本轮不加入：今日之裙、穿搭、衣橱、画廊、馆藏、收藏、解锁、连续奖励、猫咪成长或任何游戏化循环。布偶猫只作为静态视觉角色和一次性轻反馈。

## 2. 本轮视觉策略

### 2.1 首页主操作组

- 进度环之后直接进入「记录饮水」主操作组；
- 「记一杯」继续保持唯一稳定的主动作语义；
- 小口/满杯保留为同一组里的次级快捷动作；
- 以低透明纸面、细蕾丝边和轻阴影建立层级，不用更多入口或奖励提示制造热闹。

### 2.2 事实信息降噪

- 首页原本的多枚状态胶囊收敛为一张轻量事实数据条；
- 统计页使用同样的「标签 + 数值」排版，图表与时间线继续成为主要内容；
- 所有文字只描述杯数、最近一杯、平均间隔和饮水量，不表达坚持、成长或收藏。

### 2.3 布偶猫精修

- 保持代码矢量作为当前兜底，不依赖外部图片；
- 追加极轻的毛发高光、额头光泽、蝴蝶结尾部和结心高光，让 96dp 尺寸下仍然有柔软的插画质感；
- 气泡从猫盒右缘开始，避免压脸和压尾巴；
- TalkBack 将猫识别为可点按的「胆大王」，点按只产生一次轻反馈，不改变产品状态结构。

### 2.4 减少动态

- 读取系统动画缩放；
- 在减少动态时停用背景呼吸、漂浮粒子、光袋、进度环追赶、入场位移、按钮/猫咪弹性和迸发粒子；
- 记录与提醒的业务行为不受影响，减少动态只改变视觉呈现。

## 4. 外部素材声明

本轮不需要用户额外收集图片或资料。当前全部视觉变化由 Compose 绘制、代码矢量、现有主题色、纸面渐变、噪点、蕾丝和描金 token 完成。

如果后续需要真实手绘/水彩素材，开始制作前必须单独列出：图片尺寸、透明背景要求、风格参考、授权/来源和 APK 体积预算；在此之前继续使用代码资产迭代。

## 5. 验收标准

1. 首页第一眼可区分进度、主记录动作和事实摘要；
2. 「记一杯」的语义、触摸范围和现有防抖行为不变；
3. 360dp 与大字体下，主操作组、快捷饮量和猫不重叠；
4. 四主题下按钮、环心数字、数据条和统计纸面均可读；
5. 开启系统减少动态后页面不再持续播放装饰动画；
6. `./gradlew ktlintCheck` 与 `./gradlew build` 全绿；
7. 不新增持久化状态，不恢复任何游戏化或收藏语义。
