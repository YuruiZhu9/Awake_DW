# Awake_DW · v0.3 产品范围与视觉方向

- 日期：2026-09-02
- 状态：执行中
- 关系：本文件覆盖 v0.2 画廊/今日之裙相关产品决策；保留 v0.2 文档作为历史实现记录，不再作为后续产品方向。

## 1. 产品定位

Awake_DW 是一个面向所有使用者的、私有优先的喝水记录与提醒工具。

唯一的产品核心是：

1. 记录喝水；
2. 提醒喝水；
3. 查看当天与历史饮水记录；
4. 设置目标、杯量、清醒时段与提醒间隔。

视觉、文案、动效、声音与插画都只能服务于上述核心：让记录更清晰、提醒更自然、打开与使用更舒服。App 不以作品、收藏、养成或游戏循环为产品价值。

## 2. 明确不做

以下内容不再属于产品需求，也不得在后续迭代中恢复为奖励机制：

- 「今日之裙」或任何每日随机穿搭；
- 衣橱、画廊、馆藏、收藏册；
- 解锁、钉选、未读藏品、新藏品提示；
- 通过连续达标获得服装、配饰或其他内容；
- 猫的亲密度、成长、喂养、离开或惩罚；
- 以喝水记录驱动的游戏化任务与经济系统。

连续达标天数如果保留，只能作为客观统计信息，不得触发任何奖励或内容变化。

## 3. 视觉北极星

> 功能上是安静可靠的喝水工具，视觉上是精致、克制、带有 Lolita 气质的日常界面。

视觉不追求“内容很多”，而追求以下四点：

- 第一眼能看懂今天喝了多少；
- 记录操作始终是最明确的主操作；
- Lolita 元素融入界面结构，而不是堆成主题贴纸；
- 每个页面有明确主次，装饰不与信息竞争。

## 4. Lolita 视觉转译

### 4.1 允许的视觉语言

- 蕾丝：卡片边缘、分区顶部、页面边界的细饰线；
- 蝴蝶结：主操作或状态的单点视觉锚；
- 珍珠：分隔点、进度节点、细节节奏；
- 描金：极少量用于结心、细线和重点状态；
- 层叠与包边：转译为卡片、控件和内容面的层次；
- 中国传统色：作为主题色相与明暗关系，不追求花哨命名。

### 4.2 克制规则

- 单屏最多三类装饰语言；
- 装饰不得承载收藏、解锁或奖励语义；
- 主按钮、进度环、提醒状态优先于任何插画与装饰；
- 固定背景插画只作为主题氛围，不代表“今日内容”；
- 猫如保留，只是静态或轻微动效的视觉角色，可有一次点击回应，但不成长、不奖励、不惩罚。

## 5. 页面职责

### 首页

喝水主操作页。保留问候、今日进度、记录入口、提醒状态与少量辅助统计。删除画廊入口、穿搭信息和新藏品提示。

### 统计

饮水事实档案。展示今日、周趋势、时间线与必要的连续天数信息，不出现收藏或解锁表达。

### 我的

个人设置页。目标、杯量、提醒、主题、声音与文案库保持工具属性；主题选择是外观设置，不是内容收集。

### 引导

只解释提醒可靠送达所需的系统设置，不增加装饰性任务。

## 6. 技术收敛

- 删除 `Outfit`、每日穿搭、解锁、钉选与画廊导航的产品链路；
- 保留 `CatMood` 与轻量猫反馈时，移除配饰解锁和连胜驱动；
- 将全屏画卷能力改为固定主题艺术背景能力，或在暂未有素材时静默不绘制；
- 主题、间距、圆角、描边、阴影与动效时长统一进入 `:core:designsystem`；
- 真实艺术素材采用主题背景/纹理/固定装饰的命名，不再使用 outfit 目录契约；
- 资产加载必须具备采样、缓存、失败回退与体积约束。

## 7. 迭代顺序

1. 范围重置与无用机制删除；
2. 设计 token 和 Lolita 视觉组件收敛；
3. 首页信息层级重排；
4. 统计与设置页统一材质和排版；
5. 固定主题背景、纹理与猫素材；
6. 轻量动效、声音、性能与可访问性验收。

每一阶段都必须有可运行 APK、截图对比、自动化测试和真机验收记录。任何新功能必须证明不会增加理解成本，否则不进入本阶段。
