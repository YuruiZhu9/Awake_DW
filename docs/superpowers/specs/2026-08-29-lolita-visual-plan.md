# Awake_DW · 洛丽塔视觉元素设计规划

- 日期：2026-08-29
- 状态：**待用户确认浓度取向后实施**
- 关联：design.md §2 视觉设计系统、§10 显示效果优化、rules.md §一（克制与大众审美）

## 0. 一句话取向

**「穿洛丽塔的水滴」而不是「洛丽塔主题公园」**——现有布局、信息架构、水滴主标识全部不动，
洛丽塔元素以**配饰层**进入：蕾丝花边、蝴蝶结、珍珠、缎带四类元素点缀在既有结构上。
可信的判断基线：lo 元素的迷人处在于「精致的克制」——裙撑上的一圈蕾丝、领口的一枚蝴蝶结；
堆满全身就俗了。UI 同理。

## 1. 时尚元素 → UI 转译表

| 时装元素 | UI 转译 | 落点 | 分期 |
|---|---|---|---|
| 蕾丝扇贝边（scalloped lace） | 卡片顶边的扇贝花边（自绘 Shape，弧列） | 设置页分区卡、引导入口卡、庆祝横幅上下缘 | L1 |
| 蝴蝶结（ribbon bow） | 进度环 12 点方向的结饰——恰是值弧起点，「今日从蝴蝶结开始」；左右环扣 + 中结，Canvas 矢量绘制 | RingBlock 顶部；L2 再考虑引导页大水滴系结 | L1 |
| 珍珠（pearl） | 漂浮粒子加左上高光点 → 光珠观感；环心「{n}ml」两侧各一枚小珍珠分隔线 | FloatingParticles（全局四主题生效）、环心排版 | L1 |
| 缎带横幅（ribbon banner） | 达标庆祝横幅由胶囊改为缎带造型（主体 + 两端燕尾切口 + 中央微弧），文字不变 | CelebrationOverlay | L1 |
| 缎带（satin ribbon） | 进度环值弧终点小尾巴：达标时值弧满环，环外缘挂一段 8° 短飘带随呼吸微摆 | ProgressRing（仅达标态） | L1 |
| 甜系小花印花 | 极简五瓣小花 2–3 朵（低透明度、低频）加入漂浮粒子家族，与 ✦ 星芒并列 | FloatingParticles | L2（先看珍珠观感再定） |
| 描金滚边（golden trim） | 卡片描边升级为双色双线（外细金线 + 内主题色线）——深夜墨青主题与金最配 | SettingsCard | L2 |
| 花体标题字 | 系统衬线（FontFamily.Serif）用于问候语/页面标题 | 各屏标题 | L2（需真机验证各 ROM 宋体观感） |
| 裙撑/JSK/花架等具象配饰 | 不转译——过于具象， UI 化即插画堆砌 | 不做 | — |

## 2. 浓度分级（待确认）

### L1 · 点缀层（推荐先行）

- 四类元素：**蕾丝卡边 + 环上蝴蝶结 + 珍珠粒子 + 缎带横幅**（+ 达标飘带）。
- 布局零变化、零新增手势，全部是绘制层细节；性能：全部 Canvas/Shape 缓存绘制（drawWithCache/Outline），无位图、无模糊，掉帧风险≈0。
- 摘除任意一件元素，界面依然成立——这是配饰层的自检标准。

### L2 · 进阶层（可选二期）

- 描金双线卡片、甜系小花、衬线标题、引导页水滴系蝴蝶结。
- 以及**独立「甜系洛丽塔」主题**（见 §3 备选 B）。

### 明确不做（克制边界，与 rules.md §一 对齐）

1. 不引入自带字体文件（L2 仅评估系统衬线）。
2. 不做满屏蕾丝背景/大面积印花——信息可读性优先。
3. 不替换水滴主标识——蝴蝶结是配饰，不是新吉祥物。
4. 不给徽章/快捷胶囊加荷叶边——小尺寸下花边会糊成一团，保持胶囊。

## 3. 主题适配（备选 A 推荐 / 备选 B 待议）

### 备选 A · 融入现有四主题（推荐）

洛丽塔本身分甜系/古典/哥特三系——现有四主题天然对应：
草莓雾光 ≈ 甜系（Sweet）、翡翠绿 ≈ 古典系（Classic）、焦糖奶茶 ≈ 古典系暖调、深夜墨青 ≈ 哥特系（Gothic）。
**同一套配饰元素，四主题各自配色即自动成立**，不新增主题：

| 主题 | lo 系别 | 蕾丝线 laceColor | 蝴蝶结/飘带 | 珍珠高光 |
|---|---|---|---|---|
| 草莓雾光 | 甜系 | `#FFD9E4`（奶白粉） | primary 粉 | 白 65% |
| 翡翠绿 | 古典 | `#CFEADF`（薄荷白） | primary 绿 | 白 65% |
| 焦糖奶茶 | 古典暖 | `#FFEFD2`（奶油） | primary 焦糖 | 白 65% |
| 深夜墨青 | 哥特 | `#2A4A40`（暗薄荷，低透明度发光感） | primary 薄荷（微光） | 白 45%（暗底收敛） |

实现：`ThemeSpec` 增 `laceColor: Color` 字段（防漂移测试同步）；蝴蝶结复用 primary。

### 备选 B · 独立「甜系洛丽塔」主题（待议）

新增第五主题（奶油白底 + 草莓粉 + 描金，命名如「草莓塔」），固定可选不进跟随时段。
工作量：全套色板 + 防漂移测试 + 设置项。若做了 B，A 依然保留（两件事不冲突）。

## 4. 动效（克制基调：≤400ms、只达标态才动）

| 元素 | 动效 | 参数 |
|---|---|---|
| 环上蝴蝶结 | 平时静止；达标呼吸期间随微光同步轻摆（rotate ±6°，正弦反向） | 1600ms 循环，与 BreathingGlow 同拍 |
| 达标飘带 | 达标瞬间随值弧追满后淡入（180ms），次日清零消失 | fade 180ms |
| 缎带横幅 | 入场由横幅中轴向两侧展开（scaleX 0→1）+ 淡入，替代纯 fade | 300ms EaseOutCubic；出场不变 |
| 蕾丝卡边 | 静态——装饰不动画 | — |
| 珍珠粒子 | 沿用既有 48s 上浮循环，不加新动画 | — |

## 5. 逐屏落点清单（L1）

1. **首页**：RingBlock 顶部蝴蝶结（12 点方向、值弧起点）；达标态飘带 + 结饰轻摆；环心两侧珍珠点；粒子珍珠化。
2. **设置页**：三张分区卡 + 引导入口卡顶边蕾丝扇贝（Shape 层，圆角 24dp 与花边弧衔接）。
3. **庆祝层**：横幅改缎带造型（燕尾端 + 中轴展开入场）。
4. **统计页 / 引导页 / 开屏**：L1 不动（粒子珍珠化全局生效）；统计页卡片化与引导页水滴系结留 L2。
5. **深夜墨青**：蕾丝线换暗薄荷微光色，蝴蝶结与飘带用薄荷 primary——哥特 lo 的「暗夜裙」观感。

## 6. 技术要点

- `ScallopedTopShape(width 刻度自适应)`：自定义 `Shape`，Outline 路径由直线顶边替换为半圆弧列（弧径 = 卡宽 / 齿数，齿数≈屏宽 1/24dp 单位取整），`drawWithCache` 无需——Shape 由 Compose 缓存。
- 蝴蝶结/缎带/飘带/小花：全部 `Path` 矢量绘制（对称函数生成左右环扣），常量参数沉淀 `core/designsystem/lolita/` 包；与 ParticleMath 同一「纯函数可测」风格——`BowPath.generate(scale)` 单测断言路径对称性与包围盒。
- `ThemeSpec` 增 `laceColor` 后：`ThemePalette` 增 4 锚点 + `ThemePaletteTest` 快照 + 深夜主题对比度断言（lace 与 bg 亮度差 ≥ 阈值）。
- 无障碍：蝴蝶结/蕾丝纯装饰，不进语义树（`clearAndSetSemantics` 或绘制层实现天然不进）。
