## 1. 定位宣言（v0.2 的北极星）

> 打开这一眼，就值回一杯水的温柔。

v0.1 回答了「它能不能用」；v0.2 回答「它凭什么被爱」。判断标准不再是功能完备，而是三件事：
1. **打开即被包裹**——首屏 3 秒内，水彩质感、时段氛围、今日穿搭共同成立一个「场景」，而不是一个界面；
2. **每次记录都有回应**——记一杯不只是计数，是猫的一次雀跃、一段旋律、一次光的呼吸；
3. **时间留下痕迹**——连续达标解锁裙装与配饰，画廊册页变厚，「收藏」取代「坚持」成为继续使用的理由。

## 2. 体验参照系（研究结论摘要）

| 参照 | 借什么 | 落点 |
|---|---|---|
| **Alto's Odyssey** | 「会动的画」：时间轴采样渐变驱动全环境换色；细节预算意识（27 个月开发、近一年花在彩虹/萤火虫这类小细节） | 时段换肤从「四套离散色板」演进为「连续渐变采样 + 事件型氛围层」（雨后光斑、萤火虫级彩蛋） |
| **纪念碑谷** | 工艺密度：一关一主色系、色板墙全局审查、装饰只出现在功能性构件上、无失败哲学 | 四主题重新调色；洛丽塔装饰做减法（单屏装饰 ≤3 类）；所有操作可逆、错误只给柔性反馈 |
| **光·遇** | 情感回应：光袋微引导、压缩—释放情绪曲线、非语言反馈（可收集动作而非弹窗） | 猫的反馈不用文字弹窗而用动作+光效；打卡页的情绪节奏设计 |
| **旅行青蛙** | 留白与不打扰：三场景画面经济、唯一特效留给唯一互动、信息不对称制造牵挂 | 动效预算集中于「记一杯」；通知 ≤12 字；猫的状态留一点让用户自己发现的余地 |
| **Florence / Deemo** | 机制即情感、画廊式奖励（解锁插画配一段音乐，回看即响） | 画廊册页的呈现方式；里程碑短笺（v0.2 备忘） |
| **DailyArt** | 每日一件的策展仪式：单件+短导语、开屏即作品、收藏册=策展权移交 | 「今日穿搭」的开盲盒节律；画廊页信息结构 |

技法层面的硬结论（详见 §9 出处）：
- **M3 动效锚点**：转场 300–500ms、emphasized decelerate；几何/图形演出 400–700ms。
- **光袋**：可交互元素附近放 80–160dp 局部光晕，2–4s 呼吸周期，替代文字提示。
- **无失败原则**：无惩罚性红光/重震动；所有反馈可逆、柔和。
- **动效预算集中**：常驻粒子克制，唯一大演出留给「达标庆祝」与「猫的回应」。

## 3. 视觉基底定稿建议：水彩质感少女插画

既定方向（grilling Q2：A 与 B 之间）的三个候选「风味」，全部满足「水彩 + 少女感 + 洛丽塔可容纳」：

| 候选 | 描述 | 情绪 | 风险 |
|---|---|---|---|
| **α 晨雾豆沙** | 低饱和水彩，灰调粉棕，大量留白与湿画法晕染；最接近「纸上的画」 | 安静、清冷、高级感 | 可能显得寡淡，甜度不足 |
| **β 糖霜奶油** | 中高明度马卡龙色水彩，边缘保留水彩深边但整体明快；甜系可感知 | 甜、软、元气 | 控制不好会腻/塑料感 |
| **γ 时段分流**（推荐） | 不做单一风味：清晨用 α 的清冷、午后用 β 的甜、黄昏暖调、深夜墨青加银灰描边——「一天的裙子随作息换」 | 跟随作息，天然成立 | 产线要出四套调性，成本最高 |

**推荐 γ**：它与现有「四主题随作息换肤」的结构天然同构，把换肤从「换颜色」升级为「换一天的天气」。产线成本通过 AI 生成模板化解决（同一 LoRA/风格关键词 + 每主题调色后缀）。

**防「塑料感」三件套**（水彩产线规范，全部有出处，见 §9）：
1. 全局纸纹层：全屏噪点 overlay 3–5%，统一「一张纸」的质感（SVG feTurbulence / Compose 噪点着色器均可，现有 GrainOverlay 升级即可）；
2. 保留水彩深边：素材导出时保留 1–2px 边缘沉积带，禁止硬选区边与锐化；
3. 渐变一律加 dither（修 banding 从 1% 噪声起步）。

## 4. 四主题的中国色再映射（提案）

色板锚点从「硬编码十六进制 + 英文命名」升级为「中国传统色命名体系」（来源：[中国色 zhongguose.com](http://zhongguose.com)，526 色各有人文名与色值）。这只改命名与微调色相方向，不动 ThemeSpec 结构与随作息解析逻辑；实施时以该站取值为准，沿用现有色板防漂移快照测试。

| 主题 | 现名 | 中国色锚点方向（示意，实施时定值） |
|---|---|---|
| 清晨 | 翡翠绿 | 天水碧（底）、月白（面）、葱倩（强调） |
| 午后 | 草莓雾光 | 十样锦（底）、藕荷（面）、樱草（强调） |
| 黄昏 | 焦糖奶茶 | 缃叶（底）、驼牙（面）、秋香（强调） |
| 深夜 | 墨青 | 青黛（底）、鸦青（面）、月白（强调，低饱和化） |

描金（GOLD_TRIM）保留为全主题通用点睛，深夜主题降饱和呈「银灰描金」。

## 5. L3 图像底层与「今日穿搭」画廊

### 5.1 呈现规范
- **位置**：所有主页面（首页/统计/我的）底层，位于渐变背景之上、内容之下；
- **透明度与混合**：15–35% 不透明度；multiply 或 normal+低透明；与当期主题背景色相偏移 ±15° 内；可读性不足时自动加暗角遮罩；
- **深色主题**：墨青下压暗 + 降透明度（或启用同画的「夜变体」，产线同一模板加深处理）；
- **纸纹统一**：图像层并入全局纸纹体系，避免「两张纸」感。

### 5.2 收集循环（画廊制）
- **每日穿搭**：每日零点从已解锁池随机指定今日之裙，首页与底层同换——开盲盒节律（DailyArt 模式）；
- **解锁**：连续达标天数里程碑解锁新图（如 3/7/14/21/30/50/100 天各一张，具体数值开发计划定）；
- **画廊页**：新入口（首页进或统计页进，开发计划定）；册页式呈现，单件大图 + 50 字以内的裙装小注（品类名/色系/一句赏析）；可手动指定今日之裙；
- **馆藏分区（待定决策）**：画廊内设「馆藏」栏，收博物馆公有领域名画（猫/少女/花卉主题，见 §8），与 AI 产线的「裙装」并列——名画零版权成本且格调现成。

### 5.3 首发规模
10–16 张 WebP 高画质（1080×2400 或 4:5 裁切留边），总预算含猫动画在内 ≤50MB（grilling Q5 已定）。

## 6. 猫（纯陪伴 · 零惩罚）

### 6.1 形象
- **Q 版 2.5 头身水彩猫**，与裙装同一产线同一画种；默认趴在首页进度环下沿/角落（具体落位开发计划定）；
- 名字已定：**「胆大王」**。

### 6.2 行为（v0.2 MVP）
- **idle**：缓慢呼吸、偶尔甩尾、眨眼（Loop 帧动画）；
- **回应**（记一杯时）：8–16 帧手绘序列——扑水滴/蹭屏幕/舔爪开心，配气泡说话（复用心意文案库抽取逻辑，猫语气的句子另成一组）；
- **达标夜**：打呼噜睡觉，肚皮随呼吸起伏；
- **绝不惩罚**：不喝水不会饿、不会走。猫只能爱你，不能审判你（grilling Q6 铁律）。

### 6.3 成长
- 亲密度随连续达标天数缓慢成长（复用 GetStreakUseCase）；
- 解锁猫用洛丽塔配饰：素颜 → 蝴蝶结（与环上蝴蝶结同款）→ 珍珠项圈 → 小裙子——和人的裙装解锁同节奏，形成「我们一起穿裙子」的镜像；
- 实现载体建议：帧动画序列（WebP/APNG）或 Lottie；具体开发计划定。

## 7. 声音方向（新增感官维度）

- **水滴**：记一杯的「嗒咚」单音，三档随机微变调避免机械重复；
- **八音盒旋律层**：达标庆祝时一段 3–5 秒小旋律，垫在庆祝动画上（分层淡入 0.5–1s，音量比环境垫高 3–6dB——光·遇 FMOD 访谈的结构）；
- **猫声**：极轻的一声咕噜/喵（可选，做不好就砍）；
- **纪律**：尊重系统媒体音量与静音；设置页独立开关（默认开）；通知音不改动（温柔提醒的通知声保持系统默认的安静感）。
- 实现预期：SoundPool + 几个短音频文件，成本很低。

## 11. 定稿后的下一步

5. **中国色重映射 + 发版**：色板迁移（含防漂移测试）、v0.2 双包归档。

每阶段结束都有可安装 APK（日更节奏）。
