## 待验收项（本版新增 / 重点）

### 0.7.0 分层场景与粒子（重点：深夜青黛主题）

- [ ] **A-场景**：深夜青黛下首页可见中景装饰（上下两段玫瑰缎带珍珠）缓慢漂移；中央阅读区无装饰侵入，引文 / 数值对比度不降
- [ ] **B-场景**：其余七主题首页 / 统计 / 设置与 0.5.1 观感一致（试点隔离——只有青黛多了中景层）
- [ ] **C-粒子**：首页粒子密度升级（安静档 14→24 颗）后仍显克制、不闪烁、无跳跃感
- [ ] **D-帧率**：正常模式滑动 / 打卡时无明显掉帧（首页粒子 24 颗 + 中景层叠加后）；减少动态下中景层与粒子全部静止
- [ ] **E-时段**：早 / 晚切换后中景亮度有可感知但柔和的差异（夜最盛、正午最收敛）

### 0.6.0 内容策展（重点：打卡瞬间）
