# v2.2.0 · 版本 QA（2026-09-29；versionCode 46）

## 变更内容

三项并入一版（计划：`docs/superpowers/plans/2026-09-29-v220-ring-drag-plan.md` + `2026-09-29-v220-home-subtraction-and-stats-fix-plan.md`）：

- **环即把手**：沿环切向拖动即注水，整圈 = 一杯容量；15° 提交阈值，拖动中预览弧（主色 35%，只进 draw 相）+ 环心临时态「+Nml · 松手记录」；倒拨/阈值内静默取消；记账复用 `scheduleLog` 防抖闸门；环区点按保留为无障碍等价路径。进度弧 600ms tween → spring(damping 0.9, StiffnessMediumLow)，预览收场 150ms（逐帧回写），减少动态全直显。手势仲裁：累计扫过 >8° + 环带内（0.45–1.15R）+ 位移切向主导才认领，纵向滚动永远优先。designsystem 只收发几何角度，毫升换算在 feature 层 `RingDragMath`。
- **统计闪退修复（P0，2.1.0 引入）**：`MonthHeatmap` 图例取色 `HEAT_ALPHAS[index+1]` 第 5 块越界——本月数据恒非空 → 真机打开统计页必崩；既有测试填充态用旧四参构造、两节新组件从未被渲染。修复下标并新增 `StatsArchiveRenderTest` 填充态整页渲染回归。
- **首页减法**：`BadgesRow`（今日/最近一杯/平均间隔）与撤回说明行撤出首页（统计页 1.5.0 起有同款事实格与带确认的删除）；猫立绘 84→64dp、猫栏 92→72dp；首页构成收敛为 刊头问候 → 英雄行 → 缆带（事件位）→ 记一杯 → 快捷量 → 猫栏。`revertLatestCup` 与撤回回执链路保留在 HomeViewModel（3 例单测守护），仅撤 UI 入口；`AwakeConfirmDialog` 的 UI 接线测试随首页撤回入口移除（组件测试与统计页时间线删除流程仍在），如实披露。
