## 实现期决策

1. **不引入全局触点扫描框架**：Robolectric 下部分语义节点 bounds 为 0（2.0.3 起的已知环境问题），全局扫描会假阴性；逐处定点断言 + 代码核对更稳。
2. **开屏跳过不加可见提示**：它是隐藏手势，但开屏约 1.2s 自动交棒、减少动态直接跳过，不构成阻断；加提示会改变开屏观感，与保养版「零观感变化」冲突。
3. **大字允许滚动**：首页继续守「1.3× 一屏读完」；2× 允许纵向滚动，但不截断、不横向越屏、不压低触控高度。
4. **环的动作说明**：不改环心文案（引文/进度/撤回回执已各守其位），只补 `onClickLabel`，视觉零变化。
