# v0.3.0-alpha6 视觉验收清单

> 目标批次：素材接入、文案收口与视觉层次（2026-09-04）

## 视觉与交互

- [ ] 首页主任务仍然是看见今日饮水、记一杯和提醒，不出现收藏/养成/游戏语义。
- [ ] 「我的」页提醒副标题改为自然、简洁的说明；提醒状态、测试提醒和白名单入口用词易懂。
- [ ] 引导页、声音设置、文案编辑器的标题/说明/按钮不再过度诗化或机械。
- [ ] 默认心意文案可同时用于喝水反馈和猫咪气泡，句子简短、自然、不含角色专属口吻。
- [ ] 记录前使用 `beforedrink` 猫图，记录后使用 `afterdrink` 猫图；图片无白色方块，猫脸和表情清楚。
- [ ] 无第三张猫图时，晚间安静态仍然稳定显示，不出现空白或异常占位。
- [ ] Lolita 背景按主题切换，细节集中在边缘，中心留白，不能压住环、按钮、图表和设置文字。
- [ ] 五个固定主题色卡显示完整；焦糖为清透棕褐，雾紫为低饱和紫灰，不出现刺眼大色块。
- [ ] 首页/设置/引导的粒子为安静密度；统计/开屏的粒子为标准密度；减少动态后全部静止。
- [ ] 360dp 窄屏、字体放大时，猫咪、气泡、主按钮和快捷饮量不重叠。
- [ ] TalkBack 能区分主按钮、快捷饮量、导航和猫咪轻量点按。

## 人工验收限制

当前环境没有可用 Android 模拟器截图链路，因此自动化结果不能替代真机肉眼验收。发布说明会保留这一限制，并记录需要重点观察的猫图白底、素材透明度、主题切换和粒子密度。
