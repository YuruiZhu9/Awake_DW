## 本版内容（环心英雄化：只动首页视觉主角）

1. **环心数字 displaySmall 衬线**：22sp → 36sp（1.6 倍），与统计页 hero 数字同一套衬线数字语言；全屏层级归位——环心数字 > 问候语（headlineSmall）> 其余小字。字重 SemiBold、字距 -0.3sp 沿用。
2. **环体外缘发丝线退役**：环直接浮在场景画布上（与统计页周图、事实条同语言）；轨道、值弧、蝴蝶结、弧线圆头笔触不动。
3. **弧端珠扣**：弧线终点小点 → 浅珠（lace 0.90，半径 0.30×线宽）+ 发丝晕（lace 0.40 描边，半径 0.52×线宽），与统计页细轨珍珠同一件饰语言。
4. 不变量：打卡引文横切与 60dp 引文区预留（§12.3）、数字滚动 500ms、SplashMorph 开屏交接（仅共享 RING_STROKE_FRACTION，未改值）、业务与语义零改动。

## 设计决策

- 环心数字此前只有 titleLarge，被常驻引文区衬得头轻脚重——首页 90% 的注视落在环上，英雄区先立「英雄」。
- 只选「看得见的变量」（尺寸层级、环体轮廓、珠饰），不做纯减法——回应使用者对 1.5/1.6「改动不大」的持续反馈。
- 一步一发版：转场微动效（使用者点名的「顺畅感」）留给 1.8.0，等本版真机闸门。
