# v0.2 真机验收清单（艺术画廊猫计划 Task 15 预置）

> 开发者本人/用户在真机上逐项执行的检查脚本。每项跑完勾选并在备注写实际观察结果。
> 本清单随 v0.2.0 发版预置（工程全量构建绿后即打 tag），真机验收滚动进行、不阻塞发布；
> 发现问题按常规流程回修，发 hotfix 或入下版。

前置：`dist/Awake_DW-v0.2.0-debug.apk` 安装到真机（Android 13+ 优先，
覆盖一台国产 ROM——小米/华为/荣耀/OPPO/vivo 任一）。

素材说明：画卷/裙装图（`assets/outfit/`）、猫立绘（`assets/cat/`）与音效
（`core/sound/src/main/res/raw/*.ogg`）走「放入即生效」操作轨。素材未就位时按回退
语义验收——画卷不绘制、画廊/猫走矢量剪影占位、声音静默 no-op 且不崩溃；
素材就位后复验对应项（画卷/猫/声音各项标 ◇，未就位先验回退）。

发布回归：发布前用 `dist/Awake_DW-v0.2.0-release.apk`（minified）复跑第 7/8/9/12 项
（声音链路/达标庆祝/静音遵从/覆盖安装数据保留）——R8 混淆下的 SoundPool 与
DataStore 序列化兼容须单独回归。

## 清单（13 项，全部列出不得省略）

- [ ] 1. ◇ **四主题画卷可读性**：清晨/午后/黄昏/深夜四主题下，画卷与进度环、按钮、文字层次分明——画卷不过亮不抢内容，画卷以 30%/18% 透明度衬底，正文清晰可读；素材缺失时画卷静默不绘制、无崩溃。
- [ ] 2. ◇ **夜变体**：改系统时间到 22:00–05:59（深夜主题自动启用），画卷切换为压暗夜变体（或月夜冷调）；日间主题不误用夜图。
- [ ] 3. **画廊解锁网格与馆藏分区**：首页穿搭签进「衣橱」——「裙装/馆藏」页签切换正常，2 列网格按解锁日升序；锁定件呈剪影 +「第 N 天解锁 ♡」，点开无「设为今日之裙」入口。
- [ ] 4. ◇ **设为今日之裙**：详情弹层点「设为今日之裙」→ 首页画卷与穿搭签即时换装；杀进程重启后钉选仍生效；再点「取消指定」恢复每日随机。
- [ ] 5. ◇ **每日随机穿搭**：不钉选时，次日进首页换一件解锁池内裙装；同日多次进出首页不换（当日已定不重挑）。
- [ ] 6. ◇ **猫三态与配饰解锁**：白天闲坐呼吸、记一杯雀跃弹跳、22:00 后蜷缩安睡；连胜跨过阈值（如第 3 天蝴蝶结）后配饰上身穿戴，画廊与首页同步可见。
- [ ] 7. ◇ **记一杯猫气泡与水滴声**：记一杯浮出猫语气泡约 2s 收场；同时响起三选一水滴音（音频就位时）；快速连点只记一杯、只响一声。
- [ ] 8. ◇ **达标庆祝三联**：当日首次达标一拍齐发——缎带横幅 + 猫弹跳 + 八音盒旋律；同日再打卡只出掉落音与猫回应，不重播横幅与旋律。
- [ ] 9. ◇ **系统静音遵从**：系统媒体音量静音（或振动档）下记一杯与摸猫，全程无声且不崩溃（素材缺失时同样静默 no-op）。
- [ ] 10. **音效开关**：「我的 → 声音 → 音效」关闭后记一杯/达标/摸猫全静；重进设置页回显持久值；重新打开即恢复发声。
- [ ] 11. **中国色四主题整体观感**：天水碧/藕荷/缃叶/青黛逐主题过一遍——底色氛围、按钮白字对比、徽章与环心文字可读、深夜保持暗底不刺眼、蕾丝与描金不脏版。
- [ ] 12. **旧版本覆盖安装数据保留**：v0.1.1 包直装升级覆盖 v0.2.0（versionCode 2→3），历史水记录/连胜/设置/文案库全部保留；画廊解锁/钉选与音效开关以默认值出现且不崩溃；覆盖安装后桌面自适应图标正常显示。
- [ ] 13. **debug/release 双包共存**：debug 包（`applicationIdSuffix` `.debug`）与 release 包同机先后安装互不覆盖、数据互不串扰，两者桌面图标可区分。

## 补充观察项（评审顺延的交互小项）

- [ ] A. **新解锁轻提示时机**：打卡命中新解锁时「新裙入柜 ♡」浮出约 2.5s 自动收场、穿搭签回位无跳位；连续两杯不串场、不悬挂。
- [ ] B. **画廊压栈返回**：画廊页底栏隐藏；返回箭头与系统返回键均回首页原页签，返回栈不堆积（连按返回可退不出异常）。
