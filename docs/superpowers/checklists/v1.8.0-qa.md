## 本版内容（长程美学路线第一作：环体液化）

1. **环体液化**：进度 > 0 时环心内圈注水——液位与值弧同源（600ms 缓动同步上涨）、双层缓波（主波 + 半拍慢回声，7s 无缝循环）、液面高光细线。首页主角从「刻度环」变成「一只正在注水的杯子」。
2. **`MotionTokens.LIQUID_WAVE_PERIOD_MS`（7s）**：波动周期入 token 表。
3. **性能纪律**：`drawWithCache` 缓存 Path 只随尺寸重建，逐帧只 rewrite 点位——不新增逐帧分配（roadmap P1）。

## 不变量（回归确认项）

- 减少动态：波动静默、液面静止但仍显示水位；零进度不注水。
- 布局零变化：液体只在内圈绘制、clip 于轨道内壁；环心数字、打卡引文、引文区预留、蝴蝶结、珠扣全部原样。
- SplashMorph 开屏种子（0.35 进度）同步带静水位，交棒对位不受影响。
