## 2. 真机待验收（未完成）

- [ ] 八主题首页：纸边呼吸带里主题角花可辨；正文对比度不被场景抢（重点：白色圣职、黑色哥特、深夜青黛）。
- [ ] 窗环：八主题角花可辨、60 格刻度不糊、88dp 圆牌内百分比/「今日进度」完整；引文/拖环预览时遮罩够实、文字可读。
- [ ] 纸面：右上角花水印在 19% 下是「印刷」而非「污渍」；若抢字，先回 `ghostOpacity = 0.14`，再回 `paperEdgeAlpha = 0.90`。
- [ ] 压印主按钮：八主题按钮底色与字色对比、印章细节、按下手感；尾端「+250ml / 撤回」不挤主文案。
- [ ] 撕票：两枚虚线票根在 360dp/411dp 的断线是否自然；1.3×/2× 字体下不裁切、不横向越屏。
- [ ] 页眉 folio / 通栏线 / 页脚在深色主题的可见度；页脚与底栏之间的收口是否自然。
- [ ] TalkBack：环 `onClickLabel = "记一杯"`、撤回「撤回上一杯，250ml」、撕票「记 125ml」、猫提示仍常驻。
- [ ] 减少动态：窗环圆牌/遮罩直切；纸面无逐帧动画；开屏交棒处窗环出现不跳。
- [ ] 2× 字体整页滚动：页脚可达、猫栏仍单行、撕票与主按钮不重叠。
- [ ] 底栏衔接：纸面与底栏半透明底之间是否有「纸被切断」的突兀感；如需要，Phase 2 再统一底栏纸面。
