## 实现期决策

1. **共享分节件**：按 rules §二.2，第二处使用即下沉。`EditorialSectionLabel` 保留可选 trailing 槽，供文案库「恢复默认」使用；统计页三处调用逐位不变（视觉基线零漂移已证）。
2. **分区标题命名**：原「喝水提醒」卡片标题与卡内总开关同名，去卡后紧邻会重复；分区标题缩短为「提醒」，总开关仍叫「喝水提醒」，语义更清楚。
3. **步进器描边**：去卡后 ± 按钮直接落在暗色背景上，`ringTrack@45%` 在深夜青黛下边界几乎不可见；补 1dp `laceColor@32%` 描边，不改变按压/步进行为。
4. **文案库容器**：折叠分组保留 `Surface` 浅底——它是行级交互容器（可展开、可点句子），不是页面卡片；页面级卡片已全部撤除。
5. **触控高度**：「测试提醒」`TextButton` 与「让提醒更稳定」行显式 `heightIn(min = ControlMinHeight)`，新增测试按节点实际 bounds 量。
6. **拖环提示不落持久化**：AGENTS.md 禁止借视觉优化新增持久化键，因此不做「已看过」标记；以 `totalMl == 0` 为条件，`rememberSaveable` 只管进程/旋转。`hintPlayed` 在同一首页实例内只播一次，切回首页不重复；有记录时恒不显示，首杯后立即收回。
7. **提示运动学**：26° 正弦包络（0→峰值→0），1100ms 单次；珠点/虚线弧只进 draw 相，不改变真实进度、不逐帧重组。减少动态不播放移动，只保留静态「可拖动记录」。
