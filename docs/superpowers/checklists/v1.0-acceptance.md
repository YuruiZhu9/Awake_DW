# 1.0.0 收口 · 全量验收总清单（2026-09-16 建立）

> 1.0.0 是精致化阶段（0.6 提案）的收口版本：进入条件为本文清单全部闭环。本清单合并 0.4.0 以来全部 QA 的未勾选项与各版待观察项——**这是 1.0 的唯一验收文档**，走查通过即升 1.0.0（versionCode 顺延）。
>
> 反馈方式不变：每项「通过 / 不通过 + 一句话说明」，按组回传，不通过附截图。日常使用中顺手做即可，不必专项冲刺。

## A · 核心动线（每主题都走一遍）

- [ ] A1 打卡：环心白话引文 + 完整出处（—— 作者《作品名》）一眼读完；数值与进度环无位移
- [ ] A2 当日首次达标：缎带 + 光环同拍收场，克制不喧宾；减少动态下光环静默、缎带仍在
- [ ] A3 首页粒子（安静档 24 颗）：克制、无闪烁跳跃；滑动与打卡无掉帧
- [ ] A4 八主题逐一切换：场景层（雾光 / 中景 / 光斑 / 地平线）观感正常，正文对比度不降

## B · 统计与纠错

- [ ] B1 统计页近七日摘要：合计（升制）与达标天数（N/7 天）与柱状图一致
- [ ] B2 长按撤回（首页）与长按删除（统计）：确认对话框 → 回执「已撤回 · {n}ml」→ 两页重算
- [ ] B3 快速连点：「刚刚记过了」防抖回显正常

## C · 通知与开屏

- [ ] C1 提醒通知：时段标题（午安）、正文与首页问候不同句
- [ ] C2 覆盖升级（从 0.5.1 或更早 → 最新）：记录 / 主题 / 提醒 / 自写文案库全保留
- [ ] C3 冷启动开屏交棒：自写近 40 字问候时环心无明显跳动

## D · 场景层时段演化（清晨 / 深夜各看一眼）

- [ ] D1 清晨：光晕偏上、粒子偏亮、雾光收敛；深夜：雾光最盛、地平线沉底、入口「嘘，我在睡~」

- [ ] D3 AGSL 雾光（仅 Android 13+）：流动可感不喧闹；Android 12 及以下与 0.7.1 观感一致
