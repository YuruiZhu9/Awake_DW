# v2.0.0 · 版本 QA（2026-09-24；versionCode 41）

## 本版内容

1. 首页由「问候 → 花边 → 大环 → 猫 → 按钮 → 事实条」改为「日期刊头/问候 → 英雄数字 + 紧凑环 → 达标确认 → 记录动作 → 猫咪页边注 → 事实条」。
2. 今日饮水总量成为第一视觉主角；进度环只承担仪表与环心反馈。
3. 主操作前置，猫咪常驻入口保留；打卡确认、达标横幅、猫语仍在三块独立位置。
4. SplashMorph 同步新的环尺寸与落点估算。
