# v0.4–v0.5 真机验收欠账 · 补验清单（0.6.0 · 地基 A）

> 2026-09-15 建立。背景：使用者一直在真机日常使用并反馈（0.5.0、0.5.1 都由此触发），缺的不是验收习惯，而是**结构化的反馈模板**——本清单把 0.4.0–0.5.1 各版 QA 的全部未勾选项合并为一次真机走查，这就是「需要反馈什么」的答案。

## 怎么反馈（一次说明，长期有效）

- 每项回传三样：**通过 / 不通过 / 一句话说明**；不通过时加一张当时的截图；
- 不必一次做完：按 A–F 六组，做一组回传一组；
- 开头一次性告知：机型、Android 版本、是否 OLED、测试用的字体倍率（1.0 / 1.3× / 1.5× / 2×）、是否开启系统「减少动态」。

## A · 对比度（切八个主题各打卡一次）

- **A1** 环心引文正文 + 落款清晰可读——重点「深夜青黛」「黑哥特」两个深色主题（0.5.1）
- **A2** 达标缎带文字、猫语气泡文字在各自背景上可读（0.5.0）

## B · 大字体与窄屏

- **B1** 字体 1.3× / 1.5× / 2× 各打卡一次：引文折行后仍可读、不出环、数值与进度环不位移（0.5.1）
- **B2** 1.5× / 2× 下整页可滚动：「记一杯」、猫、常驻提示可达，问候不被截断（0.5.0 / 0.4.0）
- **B3** 小屏 + 三键导航壳：首屏完整、横屏扫一眼无断裂（0.4.0 遗留）

## C · 三通道同屏与动效

- **C1** 正常动态打卡：引文 + 猫语同出同收（约 3 秒），无闪烁 / 重叠 / 跳动；当日首次达标时缎带同场展开（0.5.0 / 0.5.1）
- **C2** 缎带展开的约 2.5 秒内，快捷量胶囊被短暂挤出屏幕——读起来像「有意动画」还是「乱跳」？（0.5.0）
- **C3** 开启系统「减少动态」后：引文 / 猫语 / 缎带直接出现消失，是否突兀（0.5.0 / 0.5.1）
- **C4** 减少动态下粒子、猫呼吸、开屏是否全部静止（alpha 规）

## D · 交互链路

- **D1** 长按首页「最近一杯」→ 确认对话框 → 撤回 → 环心显示「已撤回 · {n}ml」，统计页同步少一笔（0.5.0）
- **D2** 统计页时间线长按删除任意一笔：对话框正常、两页重算正确（0.5.0）
- **D3** 快速连点「记一杯」：出现「刚刚记过了」，不重复入账（0.5.0）
- **D4** 摸猫出一句猫语；22:00–06:00 猫为安睡态但入口仍可点——记录观感落差即可（方案在 0.9.0 出）
- **D5** 文案库：改一句 → 首页问候变化；删除与「恢复默认 108 句」正常（0.1.x 起）

## E · 通知与开屏

- **E1** 11:00 与 17:00 前后台各触发一次提醒：标题应为「午安」（不是「下午好」），正文取自文案库、与首页问候不同句（0.5.0）
- **E2** 覆盖升级：从 0.4.2（或 0.5.0）直接安装 0.5.1——记录、主题、提醒、自写文案库全部保留（0.5.0 / 0.4.0）
- **E3** 自写一条近 40 字问候后冷启动：开屏水滴交棒瞬间环心是否明显跳动（0.5.0）

## F · 无障碍与对话框外观

- **F1** TalkBack：环心 / 缎带 / 猫语会播报；三处长按操作在无障碍菜单可达（0.5.0）
- **F2** 四个确认对话框（撤回 / 删时间线 / 删文案句 / 整库恢复）在浅色 + 深色主题下：按钮够大、破坏性动作有视觉区分（0.5.0，无自动化截图证据，只能真机看）
