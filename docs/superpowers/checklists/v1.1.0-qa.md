## 本版内容（视觉 refresh 一阶：首页信纸化，提案 `docs/design/v1.1-visual-refresh-proposal.md`）

1. **信纸载体**：首页内容收进 `LetterSheet`——纸面与背景拉开一档、左侧贯穿边距线 + 顶端珍珠；首页 `LolitaRule` 退役（被边距线替代，不叠加图框）。
2. **尺度提级**：环心数字 → displaySmall 衬线（36sp，页面第一主角）；问候语 → 左起书信抬头（headlineSmall）。
3. **印章化**：「记一杯」方角墨印块 + 内嵌阳文细框 + 加字距铭文；按压缩放与迸发粒子不变。
4. **细钢笔环**：`RING_STROKE_FRACTION` 0.055 → 0.045、外缘蕾丝线 0.22 → 0.32；开屏交棒共用常量自动一致，`SplashMorph` 位置估算同步（`HOME_RING_STACK_ABOVE`）。
5. 业务、持久化键、导航、权限、文案、删除流程零改动；三条文字反馈通道位置不变。
