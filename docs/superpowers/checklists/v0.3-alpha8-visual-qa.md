# v0.3.0-alpha8 视觉验收清单

## 首页布局

- [ ] 猫咪在进度环之后即可看到，不需要滑到底部。
- [ ] 猫咪和气泡不遮挡今日杯数、最近一杯、平均间隔。
- [ ] 猫咪不遮挡主按钮和快捷饮量，360dp 窄屏及大字体下仍成立。
- [ ] 主进度环尺寸更克制，环心 ml 数字不再压过问候语和主操作。
- [ ] 主按钮为稳定的圆角矩形，图标底座、文字和触摸区域对齐。
- [ ] 小口/满杯快捷按钮等宽，窄屏下文字不被裁切。

- [ ] 银灰按钮使用深色文字，统计数字和问候语清晰可读。
- [ ] Lolita 哥特素材与黑白配色协调，中心信息区域仍然干净。
