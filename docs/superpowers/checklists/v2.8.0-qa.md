# v2.8.0 · 版本 QA（2026-10-22；versionCode 52）

## 变更内容

- **按压语言统一 + 状态过渡补齐**（计划：`docs/superpowers/plans/2026-10-22-v280-press-language-plan.md`；基线增补：`visual-baseline.md` §24）。
- **共享按压缩放**（`core:designsystem` 新增 `animation/PressScale.kt`）：`rememberPressScaleFraction` + `Modifier.pressScale(interactionSource)`——`MotionTokens.PRESS_SCALE = 0.97f`、spring（damping 0.5、StiffnessMedium）、`indication = null` 无水波纹、减少动态恒 1f 直显。
- **三处重复实现收敛**（rules §二.2 触发点）：`LogButton` / `ProgressRing` / 引导 `PrimaryButton` 原参数与手感逐位不变地改引用共享实现，删除各自私有的 `PRESS_SCALE` 常量与 `animateFloatAsState` 副本（引导主按钮的 `reduceMotion` 形参随之移除）。
- **次级触点接入**：`QuickSipChip`（首页快捷量）、`SelectableChip`（提醒间隔档）、`ThemeChoiceCard`（设置页色卡）、引导 `SwatchCard`、`ThemePickerEntry`、`StepButton`——`Surface(onClick)` 改为 `Box + clip/background/border + clickable(indication = null)`，role / selected 语义显式保留；水波纹退役。
- **今日时间线离场宽限**：删除一条与收起「显示更多」时，被移除的行在组合里再留一拍（`DURATION_FEEDBACK_MS` 240ms，与三通道同拍）以 `shrinkVertically + fadeOut` 收束退场；实现为展示层镜像（`shownRecords` / `shownExpanded`）按 id 求离场集合；离场中的行停用长按纠错；减少动态直删。

## 实现期抓出并修复的问题

1. **`collectIsPressedAsState` 的 Release 配对**：手工向 `MutableInteractionSource` 发射 `PressInteraction.Release` 时必须携带**原 Press 实例**（内部按实例配对移除），否则按压态不复位——探针定位（释放后停留 0.97）后修正测试发射方式；真实 `clickable` 天然成对发射，生产行为不受影响。
2. **离场集合的口径错误**（测试抓住）：初版在效果体内比较「新 expanded 的可见行 − 新目标可见行」恒为空，收起宽限被跳过。修正为展示层镜像 `shownExpanded`，效果体比较「旧镜像可见行 − 新口径可见行」；离场行从可见窗口外（收起方向）追加渲染让收束动画播完。
3. ktlint 共四轮收口：导入顺序（`pressScale` 归位 / `kotlinx.coroutines.delay` 移到 java 组之前）、`visibleOf` 表达式体→块体→参数逐行、`PressScale` 表达式体 if/else 缩进不合改块体、两处多行表达式换行。
