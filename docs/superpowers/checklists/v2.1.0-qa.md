# v2.1.0 · 版本 QA（2026-09-29；versionCode 45）

## 变更内容

- 统计页「档案化」（计划：`docs/superpowers/plans/2026-09-29-v210-stats-archive-plan.md`；方向依据：`docs/design/2026-09-29-future-directions-research.md` 候选 A，mobbin 采集 Zero 月历 / Slopes 分布条）。
- 新增**本月热力**：周一首行月历网格，五档主色透明度（0/0.20/0.42/0.66/1.0）表达每日距目标完成度，今天主色描边，未来日期淡显留空；图例「少□□□□■多」。
- 新增**时段节律**：近七日早/白天/晚堆叠分布条（主色 1.0/0.55/0.28 三段 + 2dp 纸缝）+ 图例行（色点/标签/毫升数）；时段分类沿用 `TimeSlots`，不放百分比；近七日零记录时整节静默。
- 语义等价：月历容器一条摘要（`本月有记录 x 天，达标 y 天`），TalkBack 不逐格走 31 个数字；堆叠条 contentDescription 为分布读法。
- 数据层只读新增 `WaterRepository.recentRecords(daysBack)`；月热力复用 `weekBars(daysBack = 今天几号)`，零新增聚合查询。业务写入、持久化键、导航、权限、首页零改动。
