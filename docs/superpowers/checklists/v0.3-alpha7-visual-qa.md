# v0.3.0-alpha7 视觉验收清单

## 布局与可读性

- [ ] 首页统计行的今日杯数、最近一杯、平均间隔始终完整可见，不被猫咪或气泡遮挡。
- [ ] 猫咪位于事实统计行之后，猫语气泡向上展开，窄屏滚动时也不覆盖主按钮和快捷饮量。
- [ ] 快捷饮量按钮等宽，图标、文字和触摸区域在 360dp 与常规宽屏下保持对齐。
- [ ] Lolita 背景比 alpha6 更容易辨认，但不抢进度环、主按钮、统计数字和设置文字的注意力。
- [ ] 背景图切换仍保持淡入，不出现空白闪烁或黑色方块。
- [ ] 粒子、按压、进度环和猫咪反馈动画保持克制；减少动态后仍全部静止。
- [ ] TalkBack 仍可发现主按钮、快捷饮量、猫咪和底部导航。

当前环境没有可用 Android 模拟器截图链路，自动化测试不能替代真机肉眼验收。安装 alpha7 后重点检查猫咪与统计行的垂直关系、Lolita 背景在浅色主题下的可见度，以及快捷按钮的等宽效果。
