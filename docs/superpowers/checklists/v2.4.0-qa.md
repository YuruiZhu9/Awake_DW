# v2.4.0 · 版本 QA（2026-09-29；versionCode 48）

## 变更内容

- **引导页主题实时预览**（方向研究候选 E，onboarding 2026 的 outcome preview；计划：`docs/superpowers/plans/2026-09-29-v240-onboarding-theme-preview-plan.md`）。
- 引导最前新增「先挑一个顺眼的主题」步：点选色卡即经 `prefs.setThemeChoice` 落库，app 壳的主题流（`ResolveThemeUseCase`）本就响应式——整屏随之即时换装，选完即见所得；步内嵌所选主题的「首页缩样」面板（问候 + 118dp 进度环 + 记一杯小胶囊，`AwakeTheme` 局部覆写）与八张主题色卡（复用设置页缩略图策略：渐变底 + 主题画 + 蕾丝覆层 compact）。
- 白名单步原样后移：水滴插画、权限时序、跳转序列、「以后再说」触控下限全部不变；「先用默认主题」与「就这个，继续」双出口，跳过主题选择不写偏好。
- `themeLabelOf`/`themeIdOf` 纯映射自 settings 内部提升至 `core:designsystem`（`ThemeChoices.kt`）共享，设置页与两个测试改引用、删内部副本；主题叫法全 app 一份。
- 边界：不加账号、不加网络、不增引导出口、不改导航结构与持久化键。
