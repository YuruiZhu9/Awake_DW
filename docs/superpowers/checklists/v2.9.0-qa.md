# v2.9.0 · 版本 QA（2026-10-22；versionCode 53）

## 变更内容

- **过渡补完**（计划：`docs/superpowers/plans/2026-10-22-v290-transition-completion-plan.md`；基线增补：`visual-baseline.md` §25）。
- **底栏收编**：`AwakeBottomBar` 经 `CompositionLocalProvider(LocalIndication provides NoIndication)` 关停 `NavigationBarItem` 库存涟漪；逐签 `remember { MutableInteractionSource() }` 传入 item 并接 `pressScale`——按压 = 图标 0.97 缩放回弹，与 1.9.0 选中 1.08 spring 弹入叠乘。
- **`NoIndication`**（`core:designsystem` 新增）：no-op `IndicationNodeFactory` 单例（显式恒等 equals/hashCode——该接口以工厂相等性做节点缓存键）。
- **文案分组**（`CopyGroup`，提为 internal 供测试）：展开/收起 `AnimatedVisibility`（入 `DURATION_FEEDBACK_MS` 240ms expandVertically+fadeIn / 出组件私有 `COLLAPSE_EXIT_MS` 170ms shrinkVertically+fadeOut）+ 箭头 `animateFloatAsState` 插值；分组头与「＋ 新增一句」`indication = null`。
- **引导步进**：`when (state.step)` 包进 `AnimatedContent`（fadeIn 240 / fadeOut `STEP_EXIT_MS` 170，EasingStandard，`togetherWith`；两步均 fillMaxSize 原地淡切无位移）。
- 三处减少动态均走 `motionDurationMillis(…, 0)` 直切直显。

## 实现期决策与问题

1. **测试载体**：全量 `SettingsScreen` 的常驻粒子层在动效开启下使 `waitForIdle` 永不返回（`CopyEditorTouchTargetTest` 顶部注释同源问题，首跑挂起后停掉重写）。改为把 `CopyGroup` 提为 internal 直接组合——动效开启 + 冻结时钟的离场拍断言得以成立，设置页其余场景不受影响。
2. **`IndicationNodeFactory` 包名**：实际在 `androidx.compose.foundation`（非 `.indication`），且接口显式要求实现 equals/hashCode（字节码核对 + 编译器提示修正）。
3. **分节入场不做**：页签转场（240ms 淡入+视差+微缩放）已是页面级入场，分节错峰会叠两层动画（Emil：同一次出现不叠两层）；设置步进器数值不滚动（快速连点场景瞬时优先）。两项入 §25「不补间清单」。
