# v0.3 视觉验收清单

> 当前执行批次：v0.3.0-alpha2 · 首页构图与视觉细化（2026-09-03）

- 日期：2026-09-03
- 目标：验证喝水工具的清晰性，以及克制的 Lolita 视觉表达。
- 素材声明：本轮不需要用户额外收集图片或资料；布偶猫使用代码矢量形象，页面氛围使用现有主题色与绘制层。
- 如果后续引入真实手绘/水彩素材，先单独补充尺寸、风格、授权和体积说明，再进入实现。

## 验收前提

- 安装 `dist/Awake_DW-v0.3.0-alpha2-debug.apk`；
- Android 13+ 优先，同时覆盖一台 360dp 左右窄屏设备；
- 在系统设置中分别观察浅色主题、深夜主题和大字体（fontScale 1.3）。

## 清单

- [ ] 1. 首页第一眼能看懂今日饮水总量、目标进度和「记一杯」主操作；
- [ ] 2. 「记一杯」文案在四主题下保持一致，水滴图标与文字垂直居中；
- [ ] 3. 进度环外圈细边、端点珍珠和顶部蝴蝶结清晰但不抢数字；
- [ ] 4. 首页背景的双侧水彩洗染不压低文字和按钮对比度；
- [ ] 5. 首页粒子保持轻量，星芒/花朵不遮挡进度环、按钮和猫；
- [ ] 6. 布偶猫三态都保持完整：重点色耳尖、面部面具、蓝宝石眼、围脖和微蝴蝶结可辨识；
- [ ] 7. 摸猫只产生一次轻量回应，不影响喝水统计和页面布局；
- [ ] 8. 360dp 窄屏和大字体下，猫、快捷饮量和「记一杯」不重叠，按钮可滚动到完整位置；
- [ ] 9. 统计页「近七日」与「今日记录」采用轻量纸面面板，图表和时间线仍清晰；
- [ ] 10. 设置页主题选择以色卡式两列布局显示，四主题色点和文字均可读；
- [ ] 11. 底部导航有细描边和轻阴影，选中态清楚，切换不堆栈；
- [ ] 12. 深夜主题下背景、进度环、按钮、纸面面板和布偶猫均不刺眼；
- [ ] 13. 开启系统减少动态后，背景呼吸、粒子、光袋、入场位移和进度追赶均静止，核心内容仍然可用；
- [ ] 14. TalkBack 能区分「记一杯」、两枚快捷量、三枚底部导航和可点按的「胆大王」；
- [ ] 15. 中端真机连续记录和切换页面无明显掉帧、闪烁或黑色方块；
- [x] 16. 首页顺序清晰：进度环之后首先看到「记录饮水」主操作组，事实数据条不抢主按钮焦点（代码验收；真机仍需肉眼确认）；
- [x] 17. 猫语气泡从猫盒右缘起，不遮挡猫脸、尾巴或主操作组（代码几何与窄屏测试覆盖）；
- [x] 18. 统计页「今日概览」与首页事实数据条采用同一套标签/数值层级，未出现奖励或收藏文案；
- [x] 19. v0.3.0-alpha2 已生成 debug/release APK，`ktlintCheck`、全量 `build` 与 debug/release 单元测试通过。
