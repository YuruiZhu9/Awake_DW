# v0.1 真机验收清单（Plan B Task 15 预置）

> 开发者本人在真机上逐项执行的检查脚本。每项跑完勾选并在备注写实际观察结果；
> 全部通过后才可打 tag `v0.1.0` 发布。Task 15 后续会在此清单上扩写环境与步骤细节。

前置：`./gradlew :app:assembleDebug` 产出 debug 包并安装到真机（Android 13+ 优先，
覆盖一台国产 ROM——小米/华为/荣耀/OPPO/vivo 任一）。

发布回归：发布前用 `./gradlew :app:assembleRelease` 产出的 minified 包复跑第 6/9/10 项
（通知链路/文案即时生效/卸载重装）——R8 混淆下的通知与文案链路须单独回归。

## 清单（10 项，全部列出不得省略）

- [ ] 1. **开屏续场**：冷启动水滴→涟漪→形序完整播一次进入首页；播放中点击任意处立即跳过直达首页。
- [ ] 2. **主题过渡**：改系统时钟到早/午/晚三时段（或用「跟随时间」跨档时刻观察），主题以 0.5s 平滑过渡无硬切。
- [ ] 3. **打卡演出帧率**：开启开发者选项「GPU 条形图」，首页连点进度环记一杯，演出动画主观流畅、无明显掉帧尖峰。
- [ ] 4. **双击防抖**：快速双击「记一杯」，只记录一次（统计页杯数 +1 而非 +2）。
- [ ] 5. **达标庆祝**：当日达到目标量只庆祝一次（重复打卡不重播）；次日首次打开复位后可再次庆祝。
- [ ] 6. **通知链路**：加入电池白名单前后对比通知到达准时性；到点通知出现后点「喝啦 💧」，记一杯且通知变为「记好啦 ♡」随后自动消失。
- [ ] 7. **开机重排**：有待提醒时重启手机，开机后到点提醒仍能恢复到达。
- [ ] 8. **关提醒全静默**：关闭「温柔提醒」总开关后，等待原定提醒点，全程无任何通知打扰。
- [ ] 9. **文案即时生效**：「我的 → 心意文案库」增/删/改句子后，首页对应时段文案立即使用新库内容，无保存键。
- [ ] 10. **卸载重装**：卸载后重装，全部设置与记录还原为出厂默认值，且首次启动重新出现白名单引导页。

## 补充观察项（前期评审顺延的视觉小项）

- [ ] A. **窄屏徽章行**：360dp 宽度（或更窄）真机上，统计页三枚徽章 chip 与「平均间隔」一行不被截断/重叠，换行或挤压后仍可读。
- [ ] B. **庆祝粒子小屏形态**：小屏（高度 <560dp 窗口或小屏机型）上，达标庆祝的全屏粒子演出不与按钮/文字相互遮挡，中端机庆祝瞬间无明显掉帧。
