# Mobbin 参考采集与模式分析（2026-09-20）

> 采集方式：mobbin.com/explore 匿名可访问，趋势区真实 app 截图可直接下载分析（搜索/完整库需付费账号）。
> 素材存于 `images/mobbin-references/`（版权各归原 app，仅作内部设计参考，不入 app 资源）。
> 采集动因：使用者确认 1.4.0「背景透气」方向正确，但美观还有很大迭代空间；参考成熟 app 的普适模式来收敛迭代方向。

## 三张关键参考

### stoic.（晨间记录首页 · 深色）——气质与 Awake_DW 最接近
- 近黑暖色画布 + 纸面质感；**大号衬线问候语「Good Morning.」**锚定左上，编辑排版气质。
- 内容全部装在**大圆角扁平卡片**里：无描边、无阴影，**靠表面明度差与画布分离**。
- 卡片内边距与卡间距都极慷慨（20dp+）；单一暖色强调色（琥珀），其余全靠中性色。
- 底部浮动胶囊式导航。

### Ultrahuman（睡眠仪表盘 · 纯黑）——统计页的直接参照
- **微标签 + 巨大数值**的 hero 模式：极小、全大写、加字距的标签（TIME ASLEEP）悬在超大轻字重数值上方。
- 次级指标两列并排，中间一道**竖向发丝线**分隔——不装盒子。
- **周柱状图直接画在背景上**：无卡片容器、无坐标轴，只有柱子 + 微型日期标签。
- 底部一排**描边圆形指标 chip**（线框而非填充）。

### KakaoBank（账户总览 · 暖米白）——浅色主题参照
- **暖米色画布**（非纯白）+ 深字 + 单一黄色强调。
- 大号衬线数字（账号/余额）；白卡 + 发丝描边 + 大圆角，扁平无阴影。
- 卡内行式信息：柔和色块 squircle 图标 + 标题 + 数值 + 箭头，节奏统一。

## 提炼出的普适「高级感」手法（可迁移）

1. **微标签 + hero 数值**：小写间距大写标签压阵，大号轻字重数字当主角（Ultrahuman）。
2. **卡片靠明度差分离，不靠描边**；必须描边时只一道发丝线（stoic/Kakao）。不叠加框。
3. **图表直接浮在画布上**，不装卡片（Ultrahuman）。
4. **竖发丝线分隔并排指标**，比格子盒子更轻（Ultrahuman）。
5. **单一强调色克制使用**，中性色承担结构（三家一致）。
6. **统一大圆角 + 慷慨内边距**（三家一致）。
7. 画布避免纯白/纯灰：暖米或近黑（Kakao/stoic）。

## 二轮采集（2026-09-20，健康/记录类六张，模式互证）

匿名可访问的分类页（`/explore/mobile/...`）：`flows/logging-tracking`、`screens/dashboard`、`ui-elements/{progress-indicator,tab-bar,card}`。新增六张入 `images/mobbin-references/`：

- **Zero（断食追踪 · 纯黑）**：大号轻字重计时 hero + **周柱状图直接画在画布上**（无容器无轴线）+ 描边胶囊统计位。与 Ultrahuman 图表浮空模式完全互证。
- **Nike Run Club（纯黑）**：微型大写标签悬在 `0.00` hero 上；周图今日柱主色高亮、其余灰；统计四格**只有顶部发丝线、零盒子**；末行 Last Run 发丝行。
- **TIDE（暖沙浅色）**：暖米画布 + 衬线问候 + 扁平无边卡 + 柔色选中（无描边圈）——浅色气质样本。
- **Goodreads（米白）**：数字背后垫柔和装饰色块（编辑感）；发丝统计行。
- **MyFitnessPal（白）**：细线进度 + hero 数字 + 扁平餐卡——**0.9.2 细轨珍珠方向的外部印证**。
- **stoic. 心情记录（暗）**：大片扁平磁贴无描边，选中只靠明度变化。

### 统计页去卡片化（候选 A）的最终依据

四个健康类仪表盘（Ultrahuman / Zero / Nike / MFP）一致采用：微标签 + hero 数字；图表浮空；发丝线统计格；唯一随品牌变化的是画布色。该模式与本 app 已确认的「透气背景」方向同构——统计页照此重构，风险收敛。
