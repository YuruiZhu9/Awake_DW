# 突破方向提案稿（v2.0 候选，2026-09-22）

> 状态：**征参考、未定案**。本文是立项前的方向假设，等待使用者参考素材（见 §3）对表修订；
> 定案前不动结构性代码。流程承诺：参考 → 提案定稿 → 使用者确认 → 一步一发版真机闸门。

## 1. 诊断：为什么感觉在原地

- 1.0 以来首页骨架从未变过：问候 → 花边分隔 → 环 → 猫 → 按钮 → 事实条的单列居中构图。
- 1.1–1.3 信纸失败后矫枉过正，1.4–1.9 全部收敛为「同一骨架上的参数级打磨」（去框、字号、间距、动效）——安全但收益递减，即使用者感受的「原地迭代」。
- 突破的定义：改**构图 / 信息层级 / 交互模型**三者至少之一，且第一眼可感知。

## 2. 候选方向

### 方向一「信纸的正脸」——编辑部式构图（审美突破，推荐）

- **结构性变化**：拆掉「数字住在环里」的既有约定——衬线大数字成为版面主角（日期做刊头、问候做手写行、巨号衬线数字做构图锚点），环退为一枚小而精密的仪表（角落或数字下方细环）。
- **为何合气质**：这个 app 的魂是信纸/书卷（衬线、引文、落款已是既有语言）；编辑部排版（杂志刊头式日期、巨字、基线网格）是这套语言推到底的样子，而不是往上面贴新东西。
- **风险**：构图大改，是 1.3.x 以来首次结构动作；必须严格不回退到「盒子套盒子」（无框、不遮画、留白优先）。
- **一眼可感知**：是。首屏第一眼完全不同。

### 方向二「活的画布」——场景随滚动与时间呼吸（体验突破）

- **结构性变化**：三层场景（主图/中景/光斑）从「壁纸」变「舞台」——滚动时各层视差速率不同、光晕随时段漂移、内容像浮在活着的场景上；静态截图仍克制，动起来完全不同。
- **为何合气质**：使用者早期点名的「云上列车」的通透感即此路；顺畅感原则的场景化表达。
- **风险**：性能（复用既有缓存层，禁全屏模糊）；减少动态需整层静默；「活」与「闹」的分寸要真机裁定。

### 方向三「环即把手」——记录成为手势仪式（交互突破）

- **结构性变化**：环从显示件变操纵件——例如自环下滑出「注水单」（珍珠拖入环中记账），或环珠可拖、转环即记；记一杯按钮保留为无障碍等价路径。
- **为何合气质**：记录动作本身成为 app 的招牌瞬间；业务走同一用例与防抖闸门，不碰 D10（无积分无奖励，纯交互形态）。
- **风险**：可发现性与无障碍（必须保留按钮等价 + 首次引导）；手势误触。

## 3. 参考素材征集（向使用者）

1. 5–10 张你觉得「真好看」的 app **首屏**截图——不限品类，好看即可；
2. 每张若能附一句「具体喜欢什么」（字？留白？动效？气质？）价值翻倍；
3. 说得出名字的「哇」app 也行，可自行去 mobbin 对应类别补图；
4. 反例同样有用：「说不上为什么就是丑」的也发。

## 4. 评估标准（定案时逐条过）

- [ ] 第一眼可感知是「换骨架」而非「换衣料」
- [ ] 不违背：无框、不遮画、留白优先、衬线书卷气
- [ ] 业务/持久化键/导航结构/权限零改动（交互模型变化需保留等价路径）
- [ ] 减少动态与大字体档有完整降级
- [ ] 一步一发版，真机闸门通过才算数
