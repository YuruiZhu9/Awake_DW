# 大改版方向稿：从「主题壁纸」到「一张信纸」（2026-11-17）

> 状态：**A · 纸面器物化已选定（2026-11-17）；Phase 1 首页已落地（代码侧完成，待真机验收）**。
> 样张：`docs/design/mockups/style-tile-a-paper.png`（纸面基准）、`style-tile-b-art-integration.png`（背景图结合）、`style-tile-b-stats-plate.png`（统计卷首）；真实主题素材与色值，非最终实现。
> 约束：`rules.md` / `AGENTS.md` / `visual-baseline.md` 仍是硬边界；不改业务、持久化键、导航、权限；不做 3D、网络素材、高斯模糊、游戏化。
> 一句话：**大改不是换颜色或换间距，而是换「页面的构成语法」——纸从背景变成主体，控件从 Material 变成纸面器物，版心从「居中一列」变成编辑部网格。**

## 1. 为什么现在的改动显得是微调

对照统计/设置基线（`feature/stats/visual-baselines/stats/emerald.png`、`feature/settings/visual-baselines/settings/preferences.png`）与首页代码，问题不在细节，而在三层结构：

1. **主题素材是壁纸，不是纸面。**
   `LolitaBackdrop` 把插画铺满全屏；`ReadingField` 只在中央叠 12–16% 的洗白，`readingVeil` 也很轻。花纹密集的主题（白色圣职、黑哥特）里，正文、发丝线、开关直接压在烛台、十字架、蕾丝上——「纸」只是滤镜，阅读面并不存在。
2. **控件是通用 Material 形态。**
   主按钮是渐变小胶囊，快捷量是 chip，开关是 M3 Switch，间隔是 chip 组，步进器是圆角方块。它们只换了主题色，没有进入「信纸/器物」的语言。编辑部的气质只停留在字体、字距和分节微标签上。
3. **页面骨架自 2.0 未变。**
   首页始终是「刊头 → 英雄数字 + 环 → 胶囊按钮 → chips → 猫栏」。近年的版本都在调间距、去卡片、补提示、补撤回——都是在同一骨架上做参数级优化，所以使用者会觉得「还是那个 App」。

结论：要产生「大改」的感知，必须动 **纸面层、控件层、版心层** 中至少两层；只动颜色/间距/文案不算。

## 2. 三个方向

### A. 纸面器物化（推荐，系统级）

**概念**：每一页是一张真正的纸，铺在主题场景之上。场景从「壁纸」降为「桌面/窗外」，只在纸外与纸边露出；读、写、按都发生在纸面上。

1. **纸面层**：新增共享 `EditorialSheet`。
   - 纸色取主题的 paper/ink；纸面 92–95% 不透明，主题场景只从纸边与纸面下隐约透出（保住八主题的辨识度，又不干扰阅读）。
   - 纸张有 1–2dp 的毛边/压痕、极轻的程序化纤维噪点（只进 draw 相，一次性缓存，不用位图、不联网）。
   - 纸张上下缘可以出血到屏幕外，左右留 12–16dp 的「桌面」，不做四边悬浮的卡片——这是「页」，不是「盒子套盒子」。
2. **版心与页框**：
   - 左右版心 24–28dp；顶部页眉（日期 + 小节名 + 右侧页码 folio）；底部发丝页脚。
   - 分节改用「页眉式小标题 + 通栏发丝线」，不再依赖微标签堆叠；标题可引入首字下沉/大号衬线数字。
   - 统计页从「列表」变成「记录跨页」：左栏事实、右栏时间线（窄屏回落为单栏）。
3. **器物控件**（行为不变，只换形态）：
   - 主按钮 = 火漆印章/压印长条：左侧一枚印章纹样，文字压进纸面；按下有压印下沉与轻震，不再用渐变胶囊。
   - 快捷量 = 页边批注/邮票齿孔小票；开关 = 铜扣/压印；间隔 = 刻度尺；步进器 = 打字机键帽；环 = 压印表盘（保留拖拽与百分比）。
   - 所有新形态继续守 48dp、语义、减少动态、单击替代。
4. **动效**：翻页、墨迹晕开、压印落下；减少动态直切。

**影响面**：全 app（首页先行，设置/统计跟进）。**业务/导航/持久化零改动**。**风险**：纸张与器物的绘制质量决定成败，画廉价了会像主题商店；需要一套共享 token 与组件，工作量大；八主题纸色需逐一校准。

### B. 每日一页（首页结构重排）

**概念**：首页不再是「数字 + 环 + 按钮」，而是一张竖排的水位纸：右侧一条从页顶到页底的细水线，今日每杯是线上的墨点/刻度，水位随总量上升；英雄数字落在水线旁；主按钮是底部印章；环缩成角落的小印章或并入水线。

- **保留拖拽**：把拖环映射为沿水线上下拖动，或保留角落小环继续「环即把手」；需要新的手势规格与提示。
- **影响面**：首页大幅变化；统计页可延续记录本；设置页不变。
- **风险**：招牌环与拖拽被削弱；新信息层级需要真机验证；容易「为了不一样而不一样」。

### C. 晨昏两版（时间驱动的构图）

**概念**：同一套组件，早晨/白天/夜晚是不同版面：早晨是邀请（大问候 + 大按钮 + 空水位），夜晚是回顾（今日记录/水位 + 一句收束 + 小按钮）。首页的层级随时段重排，而不只是换问候语与背景色。

- **影响面**：首页 + 可能的统计页；情绪价值最强，最贴合「会呼吸」。
- **风险**：两套布局的维护与测试成本；需要明确切换时刻与减少动态；肌肉记忆可能不稳定。

## 3. 推荐路径

**先 A，后 C（B 视 A 的接受度再说）。**

理由：B 若没有 A 的纸面与控件语言，只是把新结构放回旧壁纸；C 需要 A 的版心与组件才能成立。A 是「大改」里风险最低、收益最广的一步：它同时解决可读性、主题噪音、控件廉价感三个真问题。

A 分三步，每步一个候选版本，不一次性重写全部页面：

1. **纸面与版心**：`EditorialSheet` + `PaperTokens` + 首页试点。最大观感收益，风险最低。
2. **器物控件**：印章主按钮、尺滑杆、压印开关、批注 chips；逐个替换，行为与触控不变。
3. **页框与细节**：页眉/folio/首字下沉/页脚/纸张噪点；统计页改记录跨页，设置页收口。

### 3.1 样张已确认的视觉决定（2026-11-17）

- **纸**：主题场景只在纸外 15px 与纸下透出；纸面 94–96% 不透明（隐约透出花纹，但不干扰阅读）；内边距 24px；纸边 1px 压痕 + 柔和投影；极轻纤维噪点（程序化、无位图）。
- **版心**：页眉日期（8.5px / 2.1px 字距）+ 右侧斜体 folio；衬线问候；通栏发丝线；底部页脚「AWAKE · 每日一页 / 第 N 页」。
- **英雄区**：衬线数字 78px + 小号 `ml`；右上 140px「压印表盘」——60 格刻度环 + 2.2px 进度弧 + 珠点；表盘可触、可拖，保留「环即把手」。
- **尺**：数字下方一条 2px 水位刻度尺，78% 处有珠点；标签 `0` / `1600 ml`。
- **主按钮**：62px 压印长条，深墨底 + 内高光/内阴影 + 1px 外框；左侧 38px 火漆/罗盘印，衬线「记一杯」，右侧 `+250ml`；不再用渐变胶囊。
- **快捷量**：三张「撕票」式页边批注，虚线顶边与竖分隔，不是 chips。
- **猫**：常驻贴纸从纸边探出，保留可见提示气泡；不改「点击我试试~」的常驻规则。
- **设置控件**：打字机键帽步进器、压印开关、刻度尺滑杆、印章票据间隔；行为、触控、读屏不变。
- **样张不是最终实现**：纸张 alpha、字号、间距需在 Compose 中按 360dp / 1.3× / 2× 重新校准；表格中的尺寸是视觉基准，不是硬编码值。

### 3.2 背景图的正确用法（2026-11-17 使用者追问后修订）

**先给结论：不丢弃。** 这些图不是壁纸，是**画框**——中心留白、四角有花/鸟笼/烛台/蕾丝。之前把内容压在中心，所以它们只能当背景；现在纸是画框里的页，图可以承担三种有理由的角色：

1. **书口（fore-edge）**：纸左右留 20–22dp，主题图作为书口/画框露出；纸面 94–96% 不透明，花纹隐约透出。图仍在场，但不再与正文抢对比度。
2. **窗环（lens dial）**：把进度环做成放大镜——环内裁一角主题图（晨雾的鸟笼/玫瑰、深夜的蓝玫瑰/珍珠、圣职的烛台/十字），中心保留 88dp 纸面圆牌显示百分比/引文。环仍是可点可拖的「环即把手」；图第一次参与核心交互，而不是躺在背后。
3. **卷首插图（plate）**：在可滚动的统计页顶部用一条 104px 的裁角图作「卷首」，加 1px 框线与图注；统计没有主 CTA，不会挤占操作。首页不推荐放整条卷首（会挤掉 CTA 与猫栏，B3 样张已暴露这个问题）。
4. **封面时刻**：开屏、引导主题步、设置主题选择继续保留全幅图——这些页面没有高密度正文，图可以做主角。

- **同一张图，不同裁切**：书口用全图，窗环用 200–240% 放大的角花，卷首用 150–180% 的横裁；不新增素材，八主题仍各自成立。
- **旋转**：现有 12s 素材轮换可以只作用于书口/窗环/卷首（同一 `ArtworkCycle`），让主题“呼吸”回来，而不是在壁纸层悄悄换图。
- **实现**：新增 `ArtworkCrop(asset, focusX, focusY, zoom)` 与 `ArtworkPlate`；`ProgressRing` 只增加一个可选的环形底图槽（不改变中心内容尺寸 88dp），不重写拖拽。书口只是 `EditorialSheet` 的 inset 与纸透明度参数。
- **验收**：八主题下窗环角花可辨、百分比与引文仍可读；书口不降低正文对比度；统计卷首不挤占首屏事实；全部减少动态/大字体/触控/语义保持。

### 3.3 纸面呼吸：不再只有边缘和表盘（2026-11-17 第二轮）

使用者反馈：纸面太实，背景只剩边缘与窗环可见。第二轮样张对比了三种做法：

- **C1 呼吸纸**：纸面在版心保持 96–98%，向页边渐透到 90% 左右，图从纸里“呼吸”出来；文字仍在实底上。
- **C2 大书口**：纸面不透明，右侧留 48dp 书口，图的画框细节成为一条真正的竖画；书页变窄，偏书籍装帧。
- **C3 纸上画**：纸面不透明，把一角主题图以 19% 印在纸上（水印），图从“背后”变成“纸上的印刷”。
- **D 推荐组合**：30dp 书口 + 纸边透 10%（90% 纸）+ 角花水印 12–16% + 窗环放大另一角。同一张图三种尺度：书口看全框、水印看角花、窗环看细节。

样张：`style-tile-c-breathing-comparison.png`（C1/C2/C3）、`style-tile-d-breathing-print.png`（D 克制版）、`style-tile-d-plus-stronger.png`（D+ 明显版）。

- **D vs D+ 校准**：D = 纸边 90% / 水印 14% / 书口 30dp；D+ = 纸边 88% / 水印 19% / 书口 34dp。两者正文都清楚，D+ 的背景更在场、D 更克制。建议以 D+ 为真机初值，若抢字再回 D。
- **可调三个旋钮**（全部进 `PaperTokens`）：
  - `paperEdgeAlpha`：版心 0.96–0.98，页边 0.88–0.92；不要低于 0.86，正文可能受损。
  - `ghostOpacity`：0.10–0.16；超过 0.18 会与正文抢。
  - `foreEdgeWidth`：24–32dp；超过 40dp 页面会变窄，需要单独校准英雄区。
- **纪律**：一页最多一个书口、一块水印、一个窗环；不叠第二张图、不叠第二个框。水印只进 draw 相、静态缓存；减少动态不变。
- **可选**：水印与窗环取不同角，让同一张图在一页里出现两次但不重复；八主题各自挑最耐看的角。
- **实现补充**：`EditorialSheet` 的纸面改为“径向 alpha 渐变 + 边缘遮罩”；水印是 `drawWithCache` 里的一次 `drawImageRect`（无位图上传、无网络）；`ArtworkCrop` 同时供书口/水印/窗环/统计卷首使用。

### 3.4 Phase 1 落地记录（2026-11-17）

首页已按 D+ 落到实处，计划与门禁见 `docs/superpowers/plans/2026-11-17-editorial-home-phase1-plan.md`。与样张的三处必要差异：

1. **桌边 10dp + 纸内呼吸带 26dp**，而不是左右各 34dp 的窄页：360dp 下内容列仍从屏幕边 28dp 起、主按钮仍 ≥82% 屏宽；总视觉带宽 36dp，背景比样张更在场。
2. **纸面呼吸改用横向渐变**：大半径径向渐变在真实页面比例下左右边永远走不到 88% 的色标（诊断渲染实测），改为左右各 26dp 从 88% 渐回 97.5%，版心实底不变。
3. **水印固定在纸右上角**，窗环角花按主题另取一角（`editorialCropsOf` 八主题表）；同一张图在一页里出现两次但不重复。真实素材存在时诊断渲染直接读 `app/src/main/assets`，不引入测试副本。

已落地：`PaperTokens` / `EditorialSheet` / `ArtworkCrop` / `RingLens` / `ProgressRing` 可选窗景与 60 格刻度 / 压印主按钮 / 撕票快捷量 / 页眉 folio + 通栏线 + 页脚；首页退役 `ReadingField`。隔离诊断渲染留档：`docs/design/mockups/editorial-home-emerald-render.png`、`editorial-home-night-render.png`（整页：含猫栏与真实背景，不含底栏；非像素基线）。统计/设置的纸面与器物化仍属 Phase 2。

## 4. 做法（不是直接改代码）

1. **先出 style tile**：方向确认后，先做一张 360×640 的静态首页 + 设置页样张（真实字体、颜色、素材、真实数字），只看「纸」和「器物」的质感；不接业务、不写正式组件。
2. **再定 token**：纸色/纸边/压痕/墨色/印章尺寸/页眉页脚/版心栅格，全部进 `core:designsystem`，禁止页面私写。
3. **再改首页**：先替换背景与版心，不改布局顺序与业务；跑视觉基线 + 1.3×/2× + 减少动态；真机走查通过后再动控件。
4. **跟进设置/统计**：沿用同一纸面与页框；设置页的分节语言升级为页眉式小标题；统计页尝试双栏记录跨页，窄屏回落单栏。
5. **每步独立可回退**：纸面层/控件层/版心层分开提交，任何一步不被接受都能退回上一步。

## 5. 验收门禁

- **可读性**：八主题下正文与控件不再依赖「洗白层」；白圣职/黑哥特的花纹只出现在纸外/纸边；正文对比度达到 WCAG AA（大字号 3:1，正文 4.5:1）。
- **大改的感知**：把新旧首页并排，第一眼能说出「这是两个不同的界面」，而不是「换了颜色」。
- **不破坏既有底线**：360dp / 1.3× / 2× 不破版；触控 ≥48dp；语义/TalkBack/减少动态/单击替代全部保留；行为、持久化、导航、权限零改动。
- **性能**：纸张噪点/压痕只进 draw 相并缓存；不新增逐帧分配；首页仍守 1.3× 一屏读完（若改为可滚动，需单独确认）。
- **视觉证据**：统计/设置基线重拍并 `AWAKE_VISUAL_BASELINE=check`；首页像素基线仍受环境限制，用隔离渲染 + 真机走查兜底。

## 6. 不做什么

- 不做 3D、玻璃拟态、高斯模糊、网络素材、积分/连击/奖励。
- 不做四边悬浮的卡片（1.3.1 已否决「盒子套盒子」）；纸是页，不是卡。
- 不借大改改动业务、持久化键、导航、权限。
- 不一次性重写全 app；每一步都要能单独回退。
