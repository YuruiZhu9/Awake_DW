# 1.1.0 · 视觉 refresh 提案（2026-09-17 立项，方向待确认）

> 使用者反馈（2026-09-17，1.0.0 收口同期）：「外观值得继续升级和优化，有时候可以考虑得更加激进一点，而不是在原有的基础上做非常小的修改。」
>
> 本文是对「激进」的定义与落地方案。红线不变：不动饮水业务 / 持久化键 / 导航 / 权限；长文本不截断；删除必确认；常驻猫提示不隐藏；无积分连击奖励语义；装饰不遮挡主要操作；不叠加重复图框；不用新素材替代现有艺术方向（本提案只动代码绘制与排版，不依赖新素材）。

## 「激进」的定义

不是换色、不是加装饰，而是动三样东西：

1. **尺度**——现在的首页是「一排小元素浮在氛围上」：问候 22sp、数字 titleLarge、环 196dp，各元素都在谦让。激进版把页面交给一个主角：今日毫升数提到 display 级（≈56sp 衬线），成为第一眼的事实；环变成它的细笔画容器。
2. **结构**——内容从「直接浮在背景上」收进一个明确的**载体**。载体的隐喻已在 moodboard 里：「深夜信纸」。现在是氛围像信纸，但内容没有被「写」在纸上；激进版让内容真的长在一张有边距线、有版面的信纸上。
3. **层级**——打卡动作从「一枚胶囊按钮」升为页面的仪式动作；引文从环心小字升为信纸正文；猫从角落装饰升为「署名」。

## 三个候选方向

### A · 信纸大版面（推荐）

把 moodboard「深夜信纸，会呼吸」从隐喻做成字面意义：

```
┌─────────────────────────────────┐
│ ┃ 九月十七日 · 星期四            │  ← 信纸日期行（衬线小字 + 左边距红线）
│ ┃                                │
│ ┃ 晚安，今天辛苦了。              │  ← 书信抬头：大号衬线问候
│ ┃                                │
│ ┃      ╭──────╮                 │
│ ┃      │ 1250 │ ml              │  ← display 级数字 + 细笔画环（钢笔线 2.5dp）
│ ┃      ╰──────╯                 │
│ ┃   「月光落在窗台上……」          │  ← 引文升为信纸正文（衬线）
│ ┃    —— 朱自清《荷塘月色》        │
│ ┃ ▓▓▓▓▓▓▓▓░░░░  每日目标 1600ml  │  ← 细轨进度（0.9.2 已有）收进纸面
│ ┃                                │
│ ┃ [ 记 一 杯 ]  小口 · 一杯半     │  ← 印章式主按钮 + 附签
│ ┃                                │
│ ┃           胆大王 🐈 ← 页边注    │  ← 猫＝署名，气泡＝页边注
└─────────────────────────────────┘
```

- **信纸载体**：内容收进一张纸（纸色与背景拉开一档明度，artwork 在纸外呼吸更多、不再被整体洗白）；左侧一条 lace 边距线贯穿全页（替代现有 LolitaRule 分隔线——同一种语言，收成一个元素，符合「不叠加重复图框」）。
- **印章式主按钮**：「记一杯」从胶囊改为深底印章块（内嵌 hairline 双框、按下墨水扩散涟漪），快捷量变成旁边的「附签」。
- **达标缎带**升级为横贯信纸的绶带条（仍是纯文字确认，D10 不变）。
- 猫＝署名、气泡＝页边注：位置与常驻性不变（基线 §3），只是版面角色升级。

### B · 暗色奢纸（深夜优先）

把深夜青黛（唯一有专属主图 + 中景的主题）定为全 app 的参照美学：整体明度下压、artwork 存在感提高、金箔色点缀。**依赖七主题素材补齐**（用户侧 pending），当下不可 fully 落地，只宜作为七主题中景到位后的第二步。

### C · 杂志编辑排版

纯排版驱动：超大衬线 masthead（「九月十七日」做报头）、非对称栏式布局、细栏线、首字下沉。激进但气质偏「新闻纸」，与 lolita/信纸的柔软方向有张力；其排版提级部分已并入 A。

## 建议：A 先行，分三步落地

| 步骤 | 内容 | 版本 |
| --- | --- | --- |
| 1 | 首页信纸化（载体 + 尺度 + 印章按钮 + 猫署名） | 1.1.0 |
| 2 | 统计页手账化（周图放大为版面主角、与 hero 数字同框；0.9.2 表格保留） | 1.2.0 |
| 3 | 全局墨水语言（双纸面板、墨水涟漪统一替换 M3 ripple、八主题逐套校色） | 1.3.0 |

每步的纪律：先在本文件补该步的设计决策与验收条件 → 实施 → `visual review` 截图八主题复查 → 全量测试 → 随版出包 → 真机走查项进 QA。

## 风险与对策

- **装饰堆积**：信纸载体替换（而非叠加）现有 LaceRule 与部分面板边框；每步落地时同步清掉被替代的旧装饰。
- **对比度**：纸面明度拉开后逐主题核一遍正文/次要字对比度（自动化已有色板测试可扩）。
- **信息密度**：信纸有边距，360dp 窄屏内容宽变窄——布局回归测试（0.9.1 建立的窄屏 + 大字体口径）全量随行。
- **素材依赖**：A 方向零新素材，纯代码绘制与排版；七主题中景到位后自然增强纸外氛围。
