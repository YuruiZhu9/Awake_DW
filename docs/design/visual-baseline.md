# Awake_DW · 视觉基线与迭代原则

> 生效日期：2026-09-08。本文是视觉与交互的长期约束；需要改变基线时，先更新本文与对应 plan，再改代码。

## 1. 核心气质
- 关键词：安静、精致、留白、纸面、手工缝线、轻 Lolita。
- Lolita 是材质语言，不是游戏化机制：蝴蝶结、蕾丝、珠点、花瓣和粒子只能服务层次与氛围，不承载奖励、收藏或养成。
- 保持现有内容优先级：问候／饮水进度 > 记录操作 > 猫咪回应 > 装饰。
- 不把页面塞满。中央阅读列与主要按钮周围始终保留呼吸空间。

## 2. 主题系统
- 每个主题都必须有：背景、主色、强调色、laceColor、粒子色组；主题切换不改变业务状态。
- 哥特、圣职、薄巧可使用专属画面图框；其余主题使用 code-native 主题色花边。禁止叠加两套边框。
- 花边默认位于左右边缘、页头分隔线与角部；不得穿过环心、正文、按钮或底部导航。
- 装饰色优先读取 ThemeSpec，不写死跨主题颜色；装饰保持低对比度，正文与操作不能因此牺牲可读性。

## 3. 交互与动效
- 「点击我试试~」是常驻可点击入口，和猫本体调用同一 onPet；不得因回应出现或结束而隐藏。
- 所有装饰动画必须确定性、低密度、可减少动态；中央阅读列透明度低于页面边缘。
- 交互反馈可以有轻微粒子／微光，但不能遮挡操作、制造连续催促或改变记录结果。
- 触控目标尽量不低于 48dp；长文本自然换行、左对齐、不截断。

## 4. 架构与代码边界
- `:core:designsystem` 只放可复用视觉能力；页面组合留在 `:feature:*`。
- 绘制层不进入语义树；业务行为不由装饰组件持有。
- 不为装饰新增网络、远程字体、随机下载资源或持久化状态；本地候选轮换只能来自已核准素材，素材预算与现有主题一致。
- UI 状态不可变；主题键、导航、饮水领域逻辑未经需求变更不得顺手修改。

## 5. 验收清单
- 八个主题均可见主题色花边／主题粒子，且不与专属图框重复。
- 首页 360dp／1.3× 字体下主操作首屏可见；1.5×／2× 字体允许滚动，但猫、常驻气泡、记一杯按钮必须可达且不互相覆盖。
- 正常动态与减少动态模式下，无明显闪烁、跳动或性能回退。
- `git diff --check`、相关单元测试、`ktlint` 与完整 build 通过后，才可称为代码验收；真机帧率、横屏、OLED 层次仍需人工验收。

## 6. 后续迭代顺序
1. 先修首屏可达性与对比度，再做边缘材质。
2. 再做猫咪反馈与粒子微动效，保持单一焦点。
3. 最后才调整排版比例、素材和页面结构；每次只改变一个视觉变量。
4. 任何新装饰先写“放在哪里、为何存在、如何不打扰”，无法回答则不做。

## 7. 规则变更与后续版本
- 后续路线图：`docs/design/roadmap.md`；每轮新增日期化 plan 和 QA，不覆盖旧版验收记录。
- 本基线覆盖 alpha11 猫提示会话内隐藏的历史要求：从 alpha12 起始终显示。
- 变更提案必须记录：用户确认、变更原因、影响主题／页面、前后对照、回归结果和可回退方案。
- 原生渲染诊断图只作辅助，不等同于真机截图；检查截图前不得宣称已完成全主题视觉复核。

## 11. 0.5.0 文字反馈与纠错补充（2026-09-10 用户确认）

装饰层、主题色、背景素材与页面骨架均不变，本节只确立**文字反馈通道**与**纠错路径**的长期约束。

- **三条文字通道物理分离**，不得再共用同一块屏幕位置：
  1. 打卡确认 → **环心**（替换「今日已喝」那一行小字），1.4s 后复位；出现在使用者刚刚看着的位置，不产生布局位移；
  2. 达标横幅 → 环下缎带，2.5s 后收回，`AnimatedVisibility` 展开/收起；这是视觉规格 §4.2 第 6 步「今日份水灵达成」的落地；
  3. 猫咪回应 → 猫语气泡，2.0s 后收场。
- **语料按用途分层**：心意文案库（108 句长句）只用于首页问候与提醒通知正文，保持可整库编辑；打卡确认与猫咪回应使用内置短句池，各自持有独立去重键。短句长度 3–14 字，不得含 `|`，不得出现第二/第三人称。（**打卡确认语的形态已于 §12 更新**：改为「引文 / 原创句 + 可选落款」，长度 2–14 字，只禁第二人称；猫咪回应池的守则不变。）
- **防抖窗口内的重复触发必须回显**：环心给出「刚刚记过了」，不做静默吞并。
- **记录可撤回**：首页「最近一杯」长按撤回当日最后一杯，统计页时间线长按删除任意一笔，两处都必须先经确认对话框。撤回成功后必须在环心交代删掉了哪一杯（`已撤回 · {n}ml`）——破坏性动作不能让数字默默变小。撤回不回滚 `celebrated_day_key`——撤回后再达标不重复庆祝。
- **长文本一律不截断**：首页问候取消 `maxLines` 与省略号，自然换行并带动页面滚动。
  - 代价已确认并接受：`SplashMorph` 推算真首页环心落点时，问候语高度按**一行**估算；问候折行越多，开屏交棒瞬间环心的位移越大。内置 108 句为 11–18 字，多数一行、少数两行，偏差限于约一个行高；只有使用者自写的超长问候（编辑器上限 40 字）会把偏差拉到两个行高以上。要收紧交棒精度，先决定是恢复截断还是把行数纳入估算，**不要只调 `GREETING_TEXT_HEIGHT_SP` 常量**。
- **隐藏手势必须写明**：长按删除类操作一律在界面上用一行小字说明，并同时提供 `customActions`——只写进无障碍描述，看得见的用户就永远发现不了。说明行的位置按"不挤占主操作"排：统计页在时间线分区内，首页放在内容列最末端（主操作之后），且只在有记录时出现。
- 触控目标继续不低于 48dp，包含对话框里的确认/取消动作。**自绘控件必须显式声明下限**：`Modifier.clickable` / `combinedClickable` 不像 M3 的 `Button` 那样自带最小交互尺寸，高度完全由内边距决定，漏写就是真的会小——本轮审计在四处抓到这个问题（引导页「以后再说」约 40dp、文案库「＋ 新增一句」约 36dp、文案行 44dp、首页事实三列完全没有下限）。统一改用 `core:designsystem` 的 `ControlMinHeight` 而非散落的 `48.dp` 字面量，并由 `OnboardingLayoutTest`、`CopyEditorTouchTargetTest`、`BadgesRowLayoutTest` 三处按节点实际 bounds 守住。

## 12. 0.5.1 打卡引文与同屏节奏补充（2026-09-11 用户确认）

装饰层、主题色、背景素材、猫的矢量形象与页面骨架均不变，本节只改**打卡确认语的形态**，以及它与猫语同屏时的**层级与节奏**。本节 §12.1 明确覆盖 §11 中「打卡确认短句 3–14 字、纯第一人称、不出现第二/第三人称」的表述。

### 12.1 打卡确认语：引文 / 原创句 + 可选落款
- 每时段 10 条 = **现代白话引文（带「作者《作品名》」完整出处落款）+ 原创短句（不带落款）**的混排。引文只取两类公有领域作品并逐条核对原文：现代中文散文摘句（作家逝世满 50 年）与西方文学短句（原文公有领域、本项目自译，不用在版权期内的他人译文）。**不含任何文言**——2026-09-15 使用者确认：文言骈句（诗文、清言、小品）的读感仍是诗，全部不用。原创句**不伪造出处**，无落款就是无落款，不写「佚名」、不编作者。
- 正文 2–15 字、一眼读完，落款随正文另起一行小字；落款总长 2–14 字、恰含一对书名号。约束为：不含 `|`、文本全局唯一、**不出现第二人称「你/您」**（保持「不对使用者说话」的口吻）。第三人称不再禁止——引文叙述与作者名都会用到，逐字禁三人称已不成立。
- **落款是合法可选形态**：有内容无落款允许；只写落款不写内容不允许。猫语池（`ShortCopies.cat*`）守则不变，仍是猫的自述短念。
- （2026-09-15 修订，覆盖本节 0.5.1 原文中的「中国古典诗文摘句」「落款为作者名」表述；换装理由与圈选记录见 `docs/superpowers/plans/2026-09-15-v060-praise-corpus-draft.md`。）

### 12.2 同屏同拍与层级定序
- 打卡确认与猫语**同时出现、同时收场**，不做错峰。两者停留时长一并延长到 3.0s——短暂停留让两处都读不完就消失，才是「不知道该看哪里」的真正成因；拉长停留、拉开层级，比拆开时间更有效。
- **引文在环心为主**（衬线正文居中 + 落款小字，借进度环圆框作视线容器）；**猫语在猫那一行为次**（字号 `bodySmall`，左对齐小胶囊）。垂直分区不得互相压盖；摸猫时环心无引文，猫语仍须独立可读。
- 三条通道的分离规则不变：打卡确认在环心、达标横幅在环下缎带、猫语在猫语气泡，不得合并到同一块位置。

### 12.3 环心零位移
- 环心小字区固定为「两行正文 + 一行落款」的最小高度，引文出现／消失不得推动数值与进度环。超过该高度时自然撑开，**不截断优先于零位移**。

## 13. alpha13 场景化方向增补（2026-09-16 使用者确认 moodboard 方向）

0.7.0 起的视觉升级以本节为基线输入；实施前仍按每版本流程另立日期化 plan。moodboard 参考：`images/moodboard/`（19 张公有领域藏品，来源见其 MANIFEST.md）；方向论证：`docs/design/alpha13-moodboard-draft.md`。定调一句话：**「深夜信纸，会呼吸」**。

1. **场景层级**：氛围背景由单层升级为三层——背景层（现有主题主图）/ 中景装饰层（透明素材，缓慢漂移与视差）/ 近景失焦层（大而柔的碎光贴边）。中央阅读区留白规则不变，装饰仍不进语义树。
2. **色彩演化**：八主题色板不动；在「主题 × 时段」上做连续氛围插值（渐变锚点、粒子色族随时间缓慢过渡），参考浮世绘天色分段与ぼかし渐变。
3. **粒子预算**：QUIET 约 14→24 颗、STANDARD 约 24→80 颗，观感标尺为靛蓝底 × 月白碎点（参考 `images/moodboard/D-indigo-dyed-under-kimono-*.jpg`）；最终颗数按真机帧率校准，低端机与减少动态维持现行降级。
4. **AGSL（API 33+ 门控）**：优先三项——夜空／雨幕式整屏渐变（ぼかし）、纸纤维噪声、柔焦辉光；SDK < 33 回退现有静态渐变 + 噪点；减少动态全部关停。
5. **边界不变**：不做 3D 引擎、不引网络资源、不做高密度闪烁；中央阅读列透明度低于边缘；任何分层素材先过尺寸预算（≤1440px、透明 PNG 入库前清理边缘）。

## 14. 0.6.0 语料纪律补充（2026-09-16 使用者确认）

- 打卡引文与心意文案库共用一条硬规则：**零文言**——任何形态的文言（诗文、骈句、清言、小品）一律不用；只写现代白话，用具体的物与动作，不堆抽象形容词与套话。
- 打卡引文语料只取现代中文散文摘句（作家逝世满 50 年、公有领域）与西方文学短句（原文公有领域、本项目自译，不用在版权期内的他人译文）；落款为「作者《作品名》」完整出处，总长 2–14 字、恰含一对书名号（覆盖 §12.1 中「落款为作者名」的表述）。
- 心意文案库沿用 §11 分层规则；默认库 108 句于 0.6.0 第三轮重写，仍为第一人称自述、可整库编辑、意向态（不写「已经喝完」）。
## 15. 2.0.0 首页结构突破：信纸的正脸（2026-09-24 使用者授权继续激进迭代）

- 触发原因：使用者明确反馈 1.9.x 仍是「在原有框架上修修补补」，第一眼没有结构变化。
- 本轮方向：采用 v2.0 候选方向一「编辑部式构图」——日期刊头/问候语/今日饮水英雄数字成为版面主角，进度环退为紧凑精密仪表。
- 首页构图由「问候 → 花边 → 大环 → 猫 → 按钮 → 事实条」改为「刊头/问候 → 英雄数字 + 小环 → 达标确认 → 记录动作 → 猫咪页边注 → 事实条」。
- 这是一项**首页构图与信息层级变更**，不改变饮水业务、持久化键、导航、权限、常驻猫咪入口与三通道文字反馈分工。
- 本轮不依赖新素材；现有八主题背景继续作为纸外场景，中央内容通过排版而非重复图框建立主次。
- 大字体、减少动态、Splash 交棒与无障碍等价路径必须随结构一起回归。
## 16. 2.0.2 有效视口几何修正（2026-09-28）

- 2.0.1 复盘：在 360dp 宽度下，28dp 双侧边距后内容宽约 304dp；132dp 环 + 14dp 间距令左栏约 158dp。主按钮被塞入左栏后，左列总高远超圆环，`Row` 高度跟随左列，产生环下空段并挤窄主 CTA。
- 正式首页必须按**可用内容视口**验收，不能把独立 `HomeScreen` 的 640dp 根高等同于包含状态栏与底导航的整机首屏。本轮以 360dp × 520dp 内容视口、fontScale 1.3 作保守自动化代理。
- 修正布局：英雄行只排数值与 132dp 仪表、垂直居中；全宽「记一杯」位于行后 10dp；快捷饮量再后置。问候降到 headlineSmall 但仍自然换行不截断，英雄数值继续为主视觉。
- 自动化必须守：CTA 宽度、CTA 与英雄行间距、英雄行高度以及 520dp 内容视口内的按钮下界。只断言按钮“存在/未越出 640dp”不足以验收。

- **窗环**（`RingLens`）：环内垫主题角花（2.1–2.3× 放大、八主题各取一角），60 格刻度、值弧、珠扣与 88dp 纸面圆牌；引文/拖环预览出现时圆牌淡出、遮罩升到 0.82，文字仍落在接近纸底的面上。默认 `lens = null` 时旧环逐位不变；点按/拖拽/`onClickLabel` 不变。
- **器物控件**：主按钮 58dp 压印长条（3dp 近直角、上缘 1dp 内高光、底部 10dp 内阴影、1dp 外框、左侧 38dp 印章），保留 2.11.0 尾端杯量/撤回；快捷量改两枚页边撕票（虚线顶边 + 竖分隔、衬线毫升数），单枚仍 ≥48dp。
- **页框**：日期行右侧两位 folio（`dayOfMonth`）+ 通栏发丝线；页脚常驻纸底「AWAKE · 每日一页 / 第 NN 页」，不随内容滚动，内容列预留 34dp 底部让行。folio/页脚是版面家具，不承载状态与操作。
- **顺带修复**：庆祝光环不再用 `fillMaxSize` 撑满英雄行（按环径 `size(diameter)` 约束，英雄数字恢复非零宽度）；`FadeUpOnce` 减少动态分支以 `Box(modifier)` 承接调用方对齐，页脚不再掉到左上角。
- **图层**：`GradientBackdrop → LolitaBackdrop → FloatingParticles → EditorialSheet → 内容`；首页退役 `ReadingField`，纸面承担阅读对比度。
- **不改**：业务、持久化键、导航、权限、主题素材、三通道位置、统计/设置页面；首页信息顺序不变。
- **真机待验收**：八主题纸边/水印对比度（白圣职/黑哥特/深夜青黛）、窗环角花可辨性、1.3×/2×、TalkBack、减少动态、底栏衔接。
