# Awake_DW · 视觉基线与迭代原则

> 生效日期：2026-09-08。本文是视觉与交互的长期约束；需要改变基线时，先更新本文与对应 plan，再改代码。

## 1. 核心气质
- 关键词：安静、精致、留白、纸面、手工缝线、轻 Lolita。
- Lolita 是材质语言，不是游戏化机制：蝴蝶结、蕾丝、珠点、花瓣和粒子只能服务层次与氛围，不承载奖励、收藏或养成。
- 保持现有内容优先级：问候／饮水进度 > 记录操作 > 猫咪回应 > 装饰。
- 不把页面塞满。中央阅读列与主要按钮周围始终保留呼吸空间。

## 2. 主题系统
- 每个主题都必须有：背景、主色、强调色、laceColor、粒子色组；主题切换不改变业务状态。
- 哥特、圣职、薄巧可使用专属画面图框；其余主题使用 code-native 主题色花边。禁止叠加两套边框。
- 花边默认位于左右边缘、页头分隔线与角部；不得穿过环心、正文、按钮或底部导航。
- 装饰色优先读取 ThemeSpec，不写死跨主题颜色；装饰保持低对比度，正文与操作不能因此牺牲可读性。

## 3. 交互与动效
- 「点击我试试~」是常驻可点击入口，和猫本体调用同一 onPet；不得因回应出现或结束而隐藏。
- 所有装饰动画必须确定性、低密度、可减少动态；中央阅读列透明度低于页面边缘。
- 交互反馈可以有轻微粒子／微光，但不能遮挡操作、制造连续催促或改变记录结果。
- 触控目标尽量不低于 48dp；长文本自然换行、左对齐、不截断。

## 4. 架构与代码边界
- `:core:designsystem` 只放可复用视觉能力；页面组合留在 `:feature:*`。
- 绘制层不进入语义树；业务行为不由装饰组件持有。
- 不为装饰新增网络、远程字体、随机下载资源或持久化状态；本地候选轮换只能来自已核准素材，素材预算与现有主题一致。
- UI 状态不可变；主题键、导航、饮水领域逻辑未经需求变更不得顺手修改。

## 5. 验收清单
- 八个主题均可见主题色花边／主题粒子，且不与专属图框重复。
- 首页 360dp／1.3× 字体下主操作首屏可见；1.5×／2× 字体允许滚动，但猫、常驻气泡、记一杯按钮必须可达且不互相覆盖。
- 正常动态与减少动态模式下，无明显闪烁、跳动或性能回退。
- `git diff --check`、相关单元测试、`ktlint` 与完整 build 通过后，才可称为代码验收；真机帧率、横屏、OLED 层次仍需人工验收。

## 6. 后续迭代顺序
1. 先修首屏可达性与对比度，再做边缘材质。
2. 再做猫咪反馈与粒子微动效，保持单一焦点。
3. 最后才调整排版比例、素材和页面结构；每次只改变一个视觉变量。
4. 任何新装饰先写“放在哪里、为何存在、如何不打扰”，无法回答则不做。

## 7. 规则变更与后续版本
- 后续路线图：`docs/design/roadmap.md`；每轮新增日期化 plan 和 QA，不覆盖旧版验收记录。
- 本基线覆盖 alpha11 猫提示会话内隐藏的历史要求：从 alpha12 起始终显示。
- 变更提案必须记录：用户确认、变更原因、影响主题／页面、前后对照、回归结果和可回退方案。
- 原生渲染诊断图只作辅助，不等同于真机截图；检查截图前不得宣称已完成全主题视觉复核。

## 8. 0.4.0 首页事实摘要
- 用户于 2026-09-08 确认：今日／最近一杯／平均间隔占满可用宽度，采用等宽栏与居中文案，不回退到左侧堆叠的内容宽布局。
- 无最近一杯时保留两项事实，均分空间；不新增虚构记录。大字体允许自然换行、增高与页面滚动。
- 猫咪长回应仍然左对齐；摘要居中只是局部排版规则，不修改其他正文约束。

## 9. 0.4.1 细节精修补充（2026-09-08 用户确认）
- 全部固定主题的主题选择缩略图与真实页面保持同一装饰策略：黑色哥特、白色圣职、薄荷巧克力继续使用专属图框，其余主题使用 `ThemeSpec.laceColor` 的低对比度 code-native 蕾丝；不叠加两套边框。
- 仅使用已有本地用户素材的主题背景候选；正常动态模式下同主题候选以 12 秒低频淡入轮换，减少动态模式保持静止，不写入持久化，不改变主题映射。
- 首页猫咪未回应时保留无语义的低对比度纸面小饰，不预置完整句子；回应文字与常驻「点击我试试~」入口规则不变。
- 统计时间线超过五条时默认展示最近五条，以 `显示更多` 展开，不改变事实总数与记录顺序。
- 心意文案仍是早/白天/晚间各 36 条，共 108 条；仅润色语气与画面感，不改变喝水提醒和猫咪回应的含义。

## 10. 2026-09-10 首页主题背景修复补充
- 用户确认：八个主题的真实首页必须展示其背景，主题选择缩略图可见不等同于页面背景已生效；首页、统计和设置真实页面共用 `LolitaBackdrop` 的全尺寸绘制契约。
- 晨雾蓝瓷、午后藕荷、黄昏奶茶、雾紫玫瑰改用用户本次提供的专属本地素材；中央继续保留阅读安全区，边缘图案不得遮挡问候、进度环、猫、主操作和摘要。
- 黑哥特、白色圣职、薄荷巧克力继续使用既有专属图框，不叠加 code-native 完整边框；深夜青黛在新主图确认前保留现有安全回退。
- 背景容器必须实际占满页面可用尺寸，并有布局回归覆盖；运行时素材继续遵守本地、可解码、最长边 1440px 与单图小于 350KB 的预算。
