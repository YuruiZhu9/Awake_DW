# 后续版本开发路线图

> 2026-09-08 建立；以 alpha12 为继承基线。这是工作优先级，不是未经确认的功能承诺。

## 已落实 · alpha12
- 猫咪常驻可点击提示；八主题均具备花边来源与主题粒子；布局延续主操作优先。
- 共享视觉组件位于 core:designsystem；主题存储键、业务与权限保持兼容。
- 实施记录：`docs/superpowers/plans/2026-09-08-v03-alpha12-visual-baseline-plan.md`。
- 发布证据：`docs/superpowers/checklists/v0.3-alpha12-visual-qa.md`。

## P0 · 下一轮先补设备验收
- 在实际 Android 设备验证 alpha11 → alpha12 同签名覆盖升级，保留记录、主题和提醒设置。
- 完整导航壳下检查 360dp、1.3×／1.5×／2× 字体、横屏、TalkBack 与减少动态设置。
- 正常／减少动态分别检查猫、粒子与页面切换；真实设备性能结论需记录设备、系统及操作步骤。
- 检查圣职浅色边饰、深夜与哥特在低亮度的阅读层次。
- 完成条件：逐项有记录；发现问题先修可达性与阅读性，不撤掉已确认的美术细节作为捷径。

## P1 · 基线稳定后的精修
- 为首页／统计／设置建立八主题、空态／有数据、长文本的稳定截图对照。
- 主题选择预览与真实页面装饰保持一致，评估小卡片可读性，不机械缩放全部花边。
- 审核背景绘制与装饰缓存开销；优先复用 Path／缓存，避免新增逐帧分配与全屏模糊。
- 完成条件：每轮只改变一个视觉变量，保留前后对照并跑全部受影响测试。

## P2 · 需用户确认后再排期
- 新主题、新素材、页面结构调整和额外交互；先写设计提案，不作为本轮默认任务。
- 不做养成、签到、奖励、收藏或与喝水无关的扩张。

## 0.4.1 · 细节精修（2026-09-08 用户确认）
- 计划：`docs/superpowers/plans/2026-09-08-v041-detail-refinement-plan.md`。
- 范围：统计时间线五条折叠、全主题缩略图/页面蕾丝策略统一、已有本地背景候选低频轮换、首页猫咪未回应留白饰、心意文案润色。
- 版本默认按 0.4.x 局部修复推进，不改变 0.4.0 的首页摘要等宽居中基线；业务、导航、权限与持久化键保持兼容。

## 每版本固定流程
1. 阅读 rules／AGENTS／视觉基线，写清范围和非目标。
2. 新增版本 plan；设计变更先取得确认，文档单独提交。
3. 小步实现、补回归测试，确认所有主题和减少动态不回退。
4. `gradlew.bat ktlintCheck build`，记录设备验收与未通过项；不把缓存命中当成新跑测次数。
5. 提升版本号，生成 Debug／Release，检查包名／版本／签名并生成校验文件。
6. 更新 CHANGELOG 和 QA，经用户要求提交推送；未经真机验收默认发布 alpha；用户指定无后缀版本时，明确待验收范围，不宣称真机稳定性通过。

## 0.4.0 阶段收口
- 本轮按用户指定编号 0.4.0，继承 alpha12 视觉基线，修复首页事实摘要等宽居中排版。
- 计划：`docs/superpowers/plans/2026-09-08-v040-home-summary-plan.md`。发布状态与证据：`docs/superpowers/checklists/v0.4.0-visual-qa.md`。
- 后续 0.4.x 优先处理设备验收与局部修复；0.5.0 需新的范围确认，不默认重做现有美术。
